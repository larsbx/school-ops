## Result and navigable evidence

The [pack index](../../curriculum/mathematics/grade-2/units/place-value/teaching-pack/README.md)
links distinct learner and teacher editions, entry and assessment-only copies,
partner cards and the bank workflow. M01 learner/workbook/cards/teacher and its
formative assessment are reused byte for byte from merged main. Existing course,
unit, six lesson, four assessment and thirteen outcome IDs are retained.
`P-PV2-03-01` and similar labels are worksheet task locators, not new curriculum
record IDs. Entry E1–E6 correspond exactly to the existing six entry prompts.

PV2 uses M01 A/B, then lessons 3–6 in 0–99; lesson 2 is deferred. PV3 uses M01 A/B
and lessons 2–6 in 0–999. Each route has concrete models, worked examples,
guided-to-independent work, conceptual checks, complete keys and follow-up.
M01 remains only the tens/ones component of outcome 001. PV2 does not establish
its hundreds component. PVX retains separate teaching, materials, checks and time.

## Validation and practical limits

- Source/link/ID tests check all repository Markdown relative links and anchors,
  learner link reachability, 28 unique new worksheet tasks with exactly one
  complete key each, thirteen outcome definitions, six lesson IDs and 26 existing
  unit-assessment item IDs. Print manifests verify all source/PDF digests and
  exclude teacher/manifest sources from learner editions.
- Arithmetic checks cover decimal equality chains in the new keys; source-guided
  inspection checks counts, comparisons, units, boundary models and explanations.
  The unchanged bank tests independently check 1,000 route/mode/seed forms,
  1,001 targeted PV3 scope cases, all 0–999 names and archived reproduction.
- Print QA checks text completeness, page geometry, embedded readable symbols,
  prompt/response grouping and the absence of link annotations/key markers in
  learner editions. `python tools/verify_print_pack.py` checks source text and
  geometry; its optional `--render-directory` exports page PNGs. All 100 rendered
  pages were visually inspected; this is authoring QA,
  not physical-print or learner-device acceptance.
- Run `python -m unittest discover -s tests -v` from the repository root.
  Generate prints with `python tools/build_print_pack.py` after installing the
  optional requirements and DejaVu Sans system fonts. The checked-in PDFs make
  teaching-pack access independent of local Python/reportlab installation.
- No actual teaching, timer-based learner session, live provider delivery or
  learner result is claimed. Proposed budgets have not been observed in a classroom.
