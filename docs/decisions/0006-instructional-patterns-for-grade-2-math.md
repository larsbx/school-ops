# 0006 — Reusable instructional patterns for Grade 2 mathematics

- Decision date: 2026-10-25 (America/New_York)
- Status: accepted design direction; authored teaching materials remain draft
- Course: [C-MATH-001](../../curriculum/mathematics/grade-2/README.md)

## Decision

The user requested an Interchange-inspired structure, then clarified that it
should be abstracted as one reusable template alongside a Khan Academy pattern
and other researched approaches, including test–teach–test and progressively
less structured responses after a model.

Create a [selectable pattern library](../../templates/instruction/README.md).
Patterns organize teaching and evidence; the existing classical progression
continues to select mathematical content, outcomes and prerequisites.
Choose a pattern for a concrete learning need rather than forcing every lesson
through the same sequence. Composition is allowed: for example, diagnose with
test–teach–test, teach with faded examples, and review with retrieval later.

## Implementation

Provide six source-backed templates: two-cycle communication, practice/feedback/
recheck, test–teach–test, worked-example fading, retrieval/spaced review and 5E
inquiry. Each includes reusable authoring prompts and an original keyed Grade 2
example. The [source register](../instructional-pattern-sources.md) distinguishes
observed source features from our adaptation and bounds the evidence.

The [Interchange book map](../../curriculum/mathematics/grade-2/course-design.md)
is one optional publishing layout, not a replacement sixteen-unit curriculum.
Its [M01 pilot](../../curriculum/mathematics/grade-2/units/place-value/two-cycle/README.md)
supplies a concrete implementation. Preserve existing stable IDs, the seven
curriculum-unit containers, PV2/PV3 boundaries and separate optional PVX.

Fading removes solution cues and response frames while retaining the mathematical
criterion. It does not require shorter explanations or withdrawal of read-aloud,
objects, drawing or other access supports. Assistance and task difficulty are
separate authoring choices. Do not score English fluency or spelling as arithmetic.

## Evidence and use

All tasks and keys are original school-ops material. External references are
identified by source, not copied into the exercise bank. Patterns do not imply
Cambridge/Khan affiliation, provider integration, a proven effect for this Grade 2
implementation, learner readiness or a schedule. Apply the existing readiness
rules to each resulting lesson and assessment; templates themselves retain placeholders.
No new approval ladder is introduced.
