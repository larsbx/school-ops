## Prompts and teacher key

These are original school-ops prompts, not retrieved Khan Academy questions.

| Item | Prompt | Teacher key and evidence |
| --- | --- | --- |
| 1 | Count a set of 18 counters, then show a different arrangement with the same total. | 18; each object counted once, total remains 18 |
| 2 | Count aloud from 96 through 102. | 96, 97, 98, 99, 100, 101, 102 |
| 3 | Write the numeral for sixty-three; say how many tens and ones it has. | 63; 6 tens and 3 ones |
| 4 | Which is greater, 54 or 45? Explain with objects or a drawing. | 54; 5 tens exceed 4 tens |
| 5 | Find 8 + 7 and describe a method. | 15; e.g. 8 + 2 + 5 |
| 6 | Find 14 − 6 and show what the subtraction means. | 8; appropriate removal, difference, or missing-addend model |

## Use the evidence

Record each skill privately as independent, demonstrated with support, or needing
review. There is no aggregate pass mark and no assumed learner result.

- Counting/notation gaps: add short object-counting and numeral practice before
  moving beyond the first place-value lesson.
- Tens/ones gaps: use lesson 1 concretely and revisit exchanges before hundreds.
- Arithmetic gaps: plan the within-20 fluency strand alongside place-value work.
- Confident explanations: consider shortening review after checking fresh examples.

This check samples entry skills. It does not certify prior-grade coverage or
course mastery, and it does not assess the full second-grade outcome set.

## Standalone administration and item criteria

Distribute only [entry-tasks.md](entry-tasks.md), working paper and a blank chart.
Keep this guide out of view. Plan 10–15 minutes with extra time or split sittings;
no calculator, deadline or aggregate pass mark. Read directions without solution
cues; allow objects, speech, drawing, pointing and adult scribing. Recognize
substantive teaching prompts as support, then give feedback after the attempt.
The learner E1–E6 labels correspond to items 1–6 above, preserving this assessment ID.

| Entry skill / item | Sufficient evidence for the sampled skill | Follow-up |
| --- | --- | --- |
| One-to-one counting / E1 | Exactly 18, each object once; rearrangement retains all objects and total | Smaller collections if uncertain; also check M01's count of twelve |
| Boundary count / E2 | 96, 97, 98, 99, 100, 101, 102 in order | Diagnostic only; difficulty beyond 99 does not block PV2 |
| Tens/ones notation / E3 | 63 with six tens and three ones, matching grouped units | Use M01 concretely for gaps |
| Comparison / E4 | 54 > 45, with groups or drawing showing five tens exceed four | Revisit modeled amounts; lesson 5 later teaches the relationship |
| Composition / E5 | 15 and a valid method, such as making ten from 8 + 2 then adding 5 | Parallel within-20 practice, not a place-value gate |
| Difference / E6 | 8 and a valid removal, difference or missing-addend model | Parallel arithmetic instruction; not a blanket place-value exclusion |
