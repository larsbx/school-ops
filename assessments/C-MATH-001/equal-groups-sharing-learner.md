# Unit 3 — equal groups and sharing: independent learner check

**Draft learner reference exemplar · proposed A-MATH-001-06 · O-MATH-001-013 components only.** These six original tasks are not copied from a provider. They are fixed examples; for each new assessment session the teacher should prepare a separate reviewed form, not reuse exposed prompts. Do this **untimed**, with a separate sitting or breaks if needed. Use up to 24 counters, blank paper/boxes or tactile equivalents. Responses may be spoken, drawn, pointed, signed or via AAC; an adult may read or scribe without suggesting an answer. Give a model, a number **with units**, and a reason. Questions concern *whole objects*.

### U3-01 — Equal groups
Make **4 equal groups with 5 counters in each**. Draw or arrange the groups. How many groups, counters in each group, and counters **in all**? Explain why none is counted twice.

### U3-02 — Changing an array
Make **3 rows of 6** counters. Rearrange those counters into **6 rows of 3**. Compare the totals and explain why changing rows did or did not change the amount.

### U3-03 — How many in each?
Share **16** counters equally among **4** pots. How many counters belong in **each pot**? Show how all the counters were distributed and how you checked.

### U3-04 — How many groups?
Place **18** counters into groups of **3**. How many **groups** can you make? Show the groups and explain how the number of groups differs from the number in one group.

### U3-05 — Double and halve
Show **double 9** with counters or a drawing. State the new total. Split that total into **two equal parts**; how many in one half? Explain how the steps undo each other.

### U3-06 — Test a claim
A classmate says: “**17** whole counters can be shared into **2 equal groups** with no extras.” Test the claim with a model, state what happens to every counter, and justify whether the groups are equal.
