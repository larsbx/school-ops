## Administration and scope

Distribute only the [learner task sheet](tens-and-ones-cycle-tasks.md).
No model answers, worked examples or answer cues during the attempt; discuss
feedback afterward. State the taught scope and support used privately.
If a full task or key has been exposed, use a fresh reviewed keyed application
before calling the response independent. A public repository is not a secure
assessment delivery interface.

This is formative cycle evidence, not the whole unit assessment. It does not
replace A-MATH-001-02/PV2, certify hundreds or establish outcomes 002–004.
Count the final amount after the addition in R4; conservation applies to the
exchange, not to the preceding addition.

## Key and outcome-specific criteria

Every task checks a component of
[O-MATH-001-001](../../curriculum/mathematics/grade-2/README.md#course-outcomes).

| Task | Key/model evidence | Criterion |
| --- | --- | --- |
| R1 | 62 = 6 tens + 2 ones; one ten contains 10 of the named single counters | Correct amount, units and ten-to-one-unit relationship |
| R2 | 48 = 4 tens + 8 ones = 3 tens + 18 ones | Both models correct; the ten is replaced by ten ones without removing amount |
| R3 | 80 = 8 tens + 0 ones | Zero means no extra single ones; eight tens still contain eighty one-units |
| R4 | 19 + 1 gives 1 ten + 10 ones = 2 tens + 0 ones = 20 | Show both stages after addition; packing preserves the twenty one-units |

Judge each task as independent, supported, needs review or not assessed.
Within this checked component, seek all four accurate models plus the requested
unit, zero and conservation reasons. An accurate numeral alone is insufficient.
A model/explanation may be spoken, drawn or demonstrated without a fixed verbal
formula. Report the tens/ones component explicitly; the broader course outcome
remains incomplete until its other taught components are checked.

## Feedback

For R1 unit confusion, rebuild one ten from named single units. For R2, reverse
the exchange while retaining the full collection. For R3, contrast zero extra
ones with no tens and no ones. For R4, separate the addition from the regrouping,
then pack ten single ones into one ten. Reassess gaps with different keyed
applications within the taught range and retain individual evidence privately.
