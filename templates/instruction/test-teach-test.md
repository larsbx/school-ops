## Copy and fill

1. **Initial task:** [short actual task; existing prerequisite; no solution cues].
2. **Interpretation:** [which response indicates a unit, representation or reasoning gap].
3. **Targeted teaching:** [specific model/activity chosen from that evidence].
4. **Second task:** [new content with the same mathematical demand and declared support].
5. **Decision:** [correct result/model/reason; review if missing; later retention/transfer check].

The first test is low-stakes diagnostic work, not a reason to withhold needed
instruction. If the topic is wholly unfamiliar, model it rather than prolonging
an unproductive test. If initial evidence is already secure, shorten teaching and
use an appropriate application. Read-aloud/objects may be permitted in both tasks;
keep those access conditions comparable.

## Original Grade 2 exemplar

C-MATH-001 / U-MATH-001-01 / L-MATH-001-01-01; outcome 001, tens/ones exchange
and zero only; 0–99. Materials: counters/ten-groups and paper.
Proposed budget: first task 4 + targeted teaching 8 + second task 5 +
feedback/decision 3 = 20 minutes; adjust rather than impose a speed threshold.

| Stage/task | Prompt | Teacher key or teaching decision |
| --- | --- | --- |
| T1 | Build 42, unpack one ten and explain | 4 tens + 2 ones = 3 tens + 12 ones; conserved amount |
| T2 | Build 60; explain zero ones | 6 tens + 0 ones; not an empty collection |
| Teach exchange if needed | Retain 31 counters, unbundle one ten and recount | 3 tens + 1 one = 2 tens + 11 ones |
| Teach zero if needed | Contrast 4 tens/no extra ones with no counters | 40 differs from 0; zero extra ones does not erase tens |
| U1, second task | Build 53, unpack one ten and explain | 5 tens + 3 ones = 4 tens + 13 ones |
| U2, second task | Build 70; explain zero ones | 7 tens + 0 ones |

Grammar: name one/ten and zero's position. Logic: test the equal value of an
exchange. Rhetoric: communicate the reason with words, a drawing or objects.
Check each model and reason separately. An improved second response informs the
next lesson; it is not a causal estimate of teaching effectiveness or proof of
durable mastery. These are comparable authoring tasks, not validated parallel forms.

For an actual independent assessment, separate learner sheets from this template
and its key. Record task exposure and substantive help privately.
Whole outcome 001 and other outcomes remain unassessed here.
