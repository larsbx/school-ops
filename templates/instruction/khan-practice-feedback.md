# Template — Targeted practice, feedback and recheck

- Pattern: khan-practice-feedback, version 1
- Source: Khan-authored practice/feedback descriptions in the [source register](../../docs/instructional-pattern-sources.md)
- Status: reusable draft template and original draft exemplar
- Complete the [common contract](README.md#common-authoring-contract).
  This abstracts a teaching loop; it is not a live provider assignment.

## Copy and fill

1. **Target:** [one named skill/component and its prerequisite].
2. **Choose entry:** [brief attempt if familiar; a model first if unfamiliar].
3. **Try:** [one or a few tasks within the taught range].
4. **Respond:** [specific feedback; staged hint/model; learner explains why it helps].
5. **Retry:** [different task checking the same relationship, after support is understood].
6. **Check independently:** [fresh keyed application without solution hints].
7. **Revisit:** [later review decision; no invented calendar or provider percentage].

Specify exactly which hints, worked examples and feedback are available.
A shown solution is instruction; reproducing it is supported practice.
Include models/reasons where the outcome needs them. Stop a cycle of guesses
and supply the prerequisite model rather than merely adding more questions.

## Original Grade 2 exemplar

C-MATH-001 / U-MATH-001-01 / L-MATH-001-01-01; O-MATH-001-001, one-ten exchange;
0–99. Entry: count a ten-group and the extra ones. Paper/counters; read-aloud allowed.
Proposed budget: entry 3 + practice/model/feedback 12 + fresh check 5 = 20 minutes,
adjustable; a later revisit is additional.

| Role | Task/input | Teacher key or response |
| --- | --- | --- |
| Entry | Build 23 in tens/ones and name a ten's value | 2 tens + 3 ones; one ten contains 10 ones |
| Practice | Unpack one ten from 54; show stages and reason | 5 tens + 4 ones = 4 tens + 14 ones |
| Hint 1 if needed | Which ten-group will you exchange, and what replaces it? | Direct attention without giving the full arithmetic |
| Hint 2 if needed | Replace that single ten-group with ten individual ones; retain all original ones | Inspect the physical exchange |
| Worked model if needed | Demonstrate the same exchange with 31, then ask the learner to explain it | 3 tens + 1 one = 2 tens + 11 ones |
| Feedback on a lost ten | Recount the one-units in both models; identify where the ten ones went | Model must preserve the original amount |
| Fresh check | Unpack one ten from 72 and explain | 7 tens + 2 ones = 6 tens + 12 ones |

Progress within this component requires a correct fresh model, units and
conservation reason, not a streak or a copied answer. If support is needed on
the check, record supported and choose a later fresh application.
Vocabulary is grammar, conservation is logic, and the explanation is rhetoric.
No hundreds or whole-outcome certification is implied.

## Provider boundary

Use the connected Khan Academy exercise tool when live assignable problems
are requested. Select only returned resources with reviewed route/scope fit.
Existing optional hundreds-route sets are not automatically PV2-safe.
Do not assume a content API, export, timer, progress import or hidden range filter.
Provider mastery labels and exercise completion do not replace local outcome
evidence. The loop also works with original paper tasks and teacher feedback.
