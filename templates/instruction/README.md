# Instructional pattern library

Reusable authoring templates, with original Grade 2 mathematics examples.
The [source register](../../docs/instructional-pattern-sources.md) records the
basis and limits of each pattern. [Decision 0006](../../docs/decisions/0006-instructional-patterns-for-grade-2-math.md)
records the user's direction. These patterns select a teaching sequence; the
course selects mathematical goals and prerequisites.

| Pattern/template | Use when | Sequence | Example component |
| --- | --- | --- | --- |
| [Interchange two-cycle](interchange-two-cycle.md) | Learners need to interpret and communicate a mathematical relationship | Context/model → focused practice → partner exchange; related second cycle → independent application | Tens/ones, outcome 001 |
| [Khan-style practice and feedback](khan-practice-feedback.md) | A named skill needs targeted practice and actionable support | Select skill → attempt or learn → hint/model → explain feedback → fresh check → later revisit | One-ten exchange, outcome 001 |
| [Test–teach–test](test-teach-test.md) | Some prerequisite knowledge is plausible but its gaps are unknown | Brief initial task → teach observed need → different comparable task | Exchange/zero, outcome 001 |
| [Worked-example fading](worked-example-fading.md) | The learner needs a model, then progressively fewer solution/output cues | Complete model → completion task → sparse prompts → independent explanation → changed application | Exchange invariant, outcome 001 |
| [Retrieval and spaced review](retrieval-and-spacing.md) | Taught content needs reactivation after a gap | Recall/reconstruct → check → brief correction → later fresh retrieval | Units, exchange and zero, outcome 001 |
| [5E inquiry](five-e-inquiry.md) | A concrete phenomenon can expose a useful relationship | Engage → explore → explain → elaborate → evaluate | Measuring one length in different units, outcome 008 |

Choose one primary pattern or a small purposeful combination. A pattern is not a
course, learning-style label or provider assignment. Do not force every row into
every lesson. The examples are authoring exemplars with teacher keys, not standalone
learner assessment sheets. Separate learner exports before administration.

## Common authoring contract

Copy the selected template and fill the same ordinary lesson/assessment fields:

| Field | Record |
| --- | --- |
| Identity and scope | Existing course/unit/lesson IDs, grade/audience, outcome component and taught range |
| Prerequisites | What the learner needs and how entry work checks it |
| Pattern and purpose | Selected pattern/version and why its sequence fits this goal |
| Task sequence | Actual prompts, representations, expected responses and complete keys |
| Support | Solution cues, response frames, manipulatives, read-aloud/scribe and partner availability |
| Time | Proposed stages plus separate practice/review time; no inferred dates |
| Evidence | Result, model and reason required; independent/supported/needs review/not assessed |
| Decision | What to revisit, what can progress and what remains unassessed |
| Provenance | Original tasks and structural sources; role-specific readiness remains separate |

Outcome IDs refer to [C-MATH-001](../../curriculum/mathematics/grade-2/README.md#course-outcomes).
A partial component never certifies the whole outcome. Actual learner records stay
private. Keep unit labels and model/reason criteria even as prompts fade.
Read-aloud, objects, drawing, pointing and an adult scribe may remain available;
record substantive solution help as support.

An author may tag a task's solution support as full model, completion, cue-only or
independent. Record response structure separately: complete exemplar, sentence/
diagram frame, labels only or blank response space. Do not simultaneously increase
number range and remove support unless that combined change has an explicit purpose.
Move forward after inspectable success on a fresh similar task; restore the
needed cue/model when evidence shows a gap. This is a local teaching decision,
not a fixed streak or universal mastery percentage.

## Source and implementation boundaries

Provider descriptions establish features, not independent evidence that our
adaptation works. Research and practice guides inform the design, with their
specific limits in the source register. No effect sizes, learner improvements
or mathematical equivalence between forms are claimed from these examples.

The Khan template abstracts practice and feedback. Requested live Khan exercise
selection must use the connected Khan Academy exercise tool and the existing
[resource workflow](../../docs/khan-academy.md). These documents do not call a
provider API, copy a question bank or change the curriculum to a standards map.
