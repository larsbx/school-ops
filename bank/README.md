# Local exercise and test banks

Status: draft. Original school-ops material; no external provider content or APIs.

| Bank | Course and scope | Implementation |
| --- | --- | --- |
| [Place value v1](place-value/README.md) | C-MATH-001, Grade 2; independent PV2/PV3 routes | `exercise_bank/place_value.py` |

The shared Python standard-library engine supplies deterministic sampling, canonical
JSON, content identities and optional drill countdowns. Banks own their curriculum
blueprints and independent validators. See the [developer workflow](../docs/exercise-bank.md)
for generation, validation, versioning and adding units or courses. This foundation
does not claim implementation of other Grade 2 units or K–12 courses.
