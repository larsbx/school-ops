## Evidence boundary: invented, not observed

The [original scenario packet](source-packet.md) contains a **fictional feeding model and invented count records**. It is suitable only for reasoning practice after teacher review. No data come from a real habitat; do not present the packet as field evidence or as proof of actual species' diets, ecological causation or population size. Any real-world extension requires age-appropriate scientific source review, traceable observations, access and reuse decisions. No actual animals, plants, unsafe field activity or personal data are required.

| Local outcome | Observable goal | Draft reference evidence |
| --- | --- | --- |
| **P1 — Evidence custody** | Distinguish a model assumption, fictional recorded sighting, calculation and unsupported causal claim; state that none is real field evidence. | R1/R3/R7; identify type and limitation without falsely claiming observation. |
| **P2 — Feeding arrows** | Draw the food-to-eater **direct** arrows; reject an unwarranted shortcut from a two-arrow path. | R2/R3, both directions and explicit non-implication. |
| **P3 — Count comparisons** | Compute sightings with units; separate count changes from unique organisms; identify unequal looking times and competing explanations. | R4–R8, correct numeric reasoning, duration, and uncertainty. |
| **P4 — Scientific explanation** | Plan a better matched repeat and present a sourced, respectful claim with a stated uncertainty. | R9–R10, matched effort and a clear limited conclusion. |

## Actual draft instructional progression

[Four 25-minute episode drafts with grammar, logic, rhetoric and exits X1–X4](lessons.md) follow E1–E4. [G1–G8 guided prompts and R1–R10 fixed reference tasks](learner.md) are paired with a [separate complete teacher key, exit-key set and outcome rubric](teacher.md). The reference questions and keys are **publicly exposed**, so they are **not fresh/secure assessments** and do not establish learner mastery. Write an unseen form only after review of criteria and administration.

**Trivium:** grammar names evidence types, feeding arrows and units; logic tests direction, competing explanations and inferential limits; rhetoric defends a claim to an absent reader using explicit citations. **Arithmetic** is the sole genuine Quadrivium connection here (recorded sighting sums/differences); geometry and astronomy are not claimed or assessed. Music is excluded.

**Access and privacy:** large print, tactile arrow cards, screen-reader-readable tables, oral response, dictation, scribing, translated instructions and AAC can preserve the scientific target without adding motor or language-speed barriers. A teacher may clarify task instructions, never supply the assessed conclusion. Do not collect names, grades, individual adjustments or class assignment links in Git.

**Owner-only promotion blockers:** approve scope, accuracy/age fit of simplified model, actual source provenance for any real science examples, fair prerequisite checks, materials and accessibility, duration, safety, complete keys and independent task freshness. Only *after scope adoption* assign canonical IDs, register records and apply [record-type readiness gates](../../../docs/curriculum-model.md). Neither this document nor passing static tests implies pedagogical approval or classroom readiness.
