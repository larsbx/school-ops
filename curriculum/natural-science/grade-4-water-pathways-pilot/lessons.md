# Four original Trivium-rich teaching episodes

**Proposed only**, each with illustrative 25 minutes. [Packet A](source-packet.md) is invented, not an experiment. Use [entry probes](entry-learner.md), [guided practice](guided-learner.md), and [teacher exit keys](teacher-guide.md). Do not infer scientific or learner mastery from these examples.

## Episode 1 — Reading versus explaining (P1; E1/E2)

Display A trial 1 (100 mL input, 72 mL collector). Ask if 28 mL 'absorbed' is a measured result.

| Action | Minutes |
| --- | ---: |
| Grammar: input, collector, mL, calculated remainder | 5 |
| Logic: identify observed, computed and unknown; counterexample to absorption guess | 6 |
| Rhetoric: explain a labeled input/output diagram for a reader absent from class | 5 |
| Practice: G1 and G2 with unit/destination feedback | 6 |
| Independent X1 | 3 |

**X1.** A trial 2 collects 68 mL after input 100 mL. Calculate 'not in collector' and state one unknown. Key: **32 mL**; destination is not recorded. Calling it absorbed is not supported. Use a fresh example if reteaching is needed.

## Episode 2 — Replication and fair conditions (P2; E1/E3)

Display A and B's four readings, ask which recorded factor changes, then calculate both means.

| Action | Minutes |
| --- | ---: |
| Grammar: replicate, average, controlled factor, compared labels | 5 |
| Logic: calculate means and test single-factor comparison | 7 |
| Rhetoric: evidence sentence with a figure, units, held labels and source qualifier | 5 |
| Practice: G3 and G5 with corrective explanation | 5 |
| Independent X2 | 3 |

**X2.** Compute A/B two-trial averages, their gap and one differing recorded label. Key: **70**, **40**, difference **30 mL**; *surface* bare/cloth changes; input and tilt match. Do not claim the physical cause was verified.

## Episode 3 — Comparing versus confounding (P2/P3; E3/E4)

Show A/C and B/C together. Ask why the latter cannot isolate surface.

| Action | Minutes |
| --- | ---: |
| Grammar: tilt, equal input, confounding, inference | 5 |
| Logic: A/C mean difference and B/C two-change counterexample | 7 |
| Rhetoric: report a limited pattern rather than a physical law | 5 |
| Practice: G4 and G6 with source-specific feedback | 5 |
| Independent X3 | 3 |

**X3.** Calculate C's mean from 26 and 30 mL; compare to A's 70 mL, name differing label and one unknown. Key: **28 mL**, gap **42 mL**, tilt differs, water destination/physical mechanism **unknown**.

## Episode 4 — Revise an unsupported claim (P3/P4; E2/E4)

Present 'B trial 1: 41 mL collected, therefore cloth absorbed 59 mL.' Separate correct subtraction from unproven interpretation.

| Action | Minutes |
| --- | ---: |
| Grammar: quoted source, calculation, inference, evidence limit | 5 |
| Logic: test the absorption claim against missing destination measures | 6 |
| Rhetoric: write and revise a bounded source-citing memo | 6 |
| Practice: G7 and G8 with feedback | 5 |
| Independent X4 | 3 |

**X4.** Rewrite the B trial 1 statement and propose an additional measurement while keeping tilt and input equal. Key: **59 mL not collected**, *not* measured absorbed; propose an independently measured standing-water volume or cloth mass before/after under a separate reviewed protocol. The specific destination remains unknown.

**Assessment boundary:** X1–X4 are distinct from coached G prompts but remain public exemplars. Permit equivalent response modes; only independent reasoned evidence supports the stated local goal.
