# Four proposed Trivium-rich teaching episodes

**Draft authoring only.** Timing is four illustrative 25-minute blocks (not a calendar or adopted teaching budget). Use [source cards](source-packet.md), [entry checks](entry-learner.md), [guided tasks](guided-learner.md) and [teacher answers](guided-teacher.md). Each independent exit is distinct from its guided prompt and keyed separately. Do not withdraw access supports during independent checks, but distinguish neutral access from content hints.

## Episode 1 — Literal report versus figurative reading (P1; requires E2)

**Teacher setup:** Display A1 and A3 side by side. Ask “Can a hallway physically swallow something? What might a writer mean by this sentence? Which words report an actual movement?” Avoid announcing the answer before first attempts.

| Work | Minutes |
| --- | ---: |
| Grammar: distinguish literal verb, personification and paraphrase using A1/A3 | 5 |
| Logic: countermodel with a hallway that has no mouth; compare permissible interpretations | 6 |
| Rhetoric: pairs explain A3 to an absent reader without inventing a swallowing event | 5 |
| Practice: guided G1/G2, immediate source-limited feedback | 6 |
| Independent X1 (record response privately) | 3 |

**Teacher move:** If an answer says a hallway literally ate a sound, contrast physical action with evoked quietness, then repeat on a fresh image before X1. **Success evidence:** X1 gives interpretation, safe literal paraphrase and a non-inference; these are jointly required.

## Episode 2 — Partial narrator and justified disagreement (P2; requires E1/E3)

**Teacher setup:** Reveal B1–B5 only after learners state what A2/A5 can establish. Model columns “observed,” “reported,” “concluded,” “still unknown,” without filling Noah's entries for them.

| Work | Minutes |
| --- | ---: |
| Grammar: define viewpoint, inference, quotation, reported speech | 5 |
| Logic: contrast B2 doorway view with B4 inside view, test B3 overclaim | 7 |
| Rhetoric: two learners explain apparently different accounts without blaming a character | 5 |
| Practice: G3/G4 and corrective source-pointer feedback | 5 |
| Independent X2 | 3 |

**Teacher move:** If learners treat B3 as verified, point out an inference requires a reason and B4 supplies counterevidence. **Success evidence:** classify B3, quote/cite B4, explain vantage limit.

## Episode 3 — Reconcile records without manufactured certainty (P3; requires E1/E3/E4)

**Teacher setup:** Present A2, C2, B4 on separate cards; ask “Does a later shelf observation contradict an earlier table observation?” Introduce the phrase “the log records” as different from “the event was independently verified.”

| Work | Minutes |
| --- | ---: |
| Grammar: name an attributed log entry versus a witness claim and time sequence | 5 |
| Logic: order reports, test theft claim and missing mover/final-check data | 7 |
| Rhetoric: describe a plausible timeline with attributed clauses and an explicit limit | 5 |
| Practice: G5/G6 with missing-source feedback | 5 |
| Independent X3 | 3 |

**Teacher move:** Do not silently identify a mover or treat a partial log as a complete inventory. **Success evidence:** three correctly attributed reports, a compatible bounded sequence and one real unknown.

## Episode 4 — Coherent audience revision and counterpoint (P4; requires E3/E4)

**Teacher setup:** Place the unsupported sentence “Noah saw empty shelves, so somebody stole every folder” on the board. Ask “Which words misstate the source? How could a reader check our replacement? What objection may remain?”

| Work | Minutes |
| --- | ---: |
| Grammar: revise pronoun references, connective words and precise line citations | 5 |
| Logic: test overclaim against B2/B4 and consider that C2 might be mistaken | 7 |
| Rhetoric: write or dictate three connected sentences for a reader without the cards | 5 |
| Practice: G7/G8 and audience-check exchange | 5 |
| Independent X4 | 3 |

**Teacher move:** Accept an oral or scribed paragraph whose source attribution is independently selected; do not let the scribe supply the warrant. **Success evidence:** accurate source detail, explicit reason and qualified limit in coherent prose. The owner must approve a genuinely new assessment form and threshold before any mastery decision.
