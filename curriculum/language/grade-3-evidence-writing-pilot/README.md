# Grade 3 language — evidence-writing pilot

**Record: authored draft, unregistered, not ready.** Intended Grade 3 learners; real prerequisites are unmeasured. Formal course, unit, lesson, outcome, assessment and resource IDs are **unassigned** until owner approval. Local labels G3-LANG-P1–P4 below are not stable IDs. Four 25-minute episode sketches are illustrative, not an agreed timetable. Nothing records learner performance.

This pilot develops [Grade 3 language planning](../../scaffolds/grade-3/language.md) without duplicating Grade 2 mathematics C-MATH-001, the Grade 2 Islamic studies prototype, or the Grade 3 mathematics/geometry/astronomy/reasoning/Islamic studies pilots. All [texts](source-packet.md) are newly written fictional prompts. No external source, copyrighted quotation, historical or religious claim is borrowed. Classroom approval, language access, source custody and authenticity of future texts remain open.

## Observable, proposed outcomes

| Local authoring label | Observable target | Fixed reference tasks |
| --- | --- | --- |
| G3-LANG-P1 | Explain a word part and confirm meaning from sentence context, distinguishing meaning from an unsupported event claim | S1–S2 |
| G3-LANG-P2 | Sequence events into a coherent explanation; distinguish what a story reports from what it does not prove | S3–S4 |
| G3-LANG-P3 | Cite an exact text detail to support or challenge a claim; identify what net arithmetic changes cannot establish | S5–S8 |
| G3-LANG-P4 | Revise an overclaim into a three-sentence, reader-facing explanation with line attribution and uncertainty | S9–S10 |

**Trivium:** Every episode requires grammar (word and sentence precision), logic (inference, counterexample or order) and rhetoric (an audience-readable explanation). The only Quadrivium art actually exercised in this language pilot is **arithmetic** with two fictional before/after table counts; geometry and astronomy receive no invented coverage credit. Music is excluded.

## Entry and teaching progression

First use four [learner entry prompts](entry-learner.md) E1–E4 and [teacher remediation/rechecks](entry-teacher.md). Grade placement does not prove readiness. If a prerequisite is absent, use the associated mini-lesson and a fresh recheck. Reading aloud, enlarged text, alternate language support, pointing cards, dictation or scribing may change access mode, not the textual-warrant requirement.

The [four substantive episode sequences](lessons.md) contain teacher language, activities, grammar/logic/rhetoric moves, independent exit X1–X4 and proposed 25-minute divisions. Their local progression is:

1. Meaning in context (E1/E2 → G3-LANG-P1); contrast *unfolded* with a false word-part guess.
2. Paragraph structure (E2 → G3-LANG-P2); order map events and separate a request from its completion.
3. Evidence and countermodels (E3 and numerical readiness → G3-LANG-P3); rebut "useless" and distinguish a net −3 from event counts.
4. Revision for an absent reader (E3/E4 → G3-LANG-P4); attribute line IDs, mark paraphrase, and weaken "proved" to "not established."

Eight [guided learner prompts](guided-learner.md) G1–G8 have a [separate keyed teacher guide](teacher-guide.md), including all four exit keys. Ten [exposed fixed reference tasks](draft-assessments/reference-learner.md) S1–S10 have a [separate full answer key and provisional rubric](draft-assessments/reference-teacher.md). Fixed reference work is **not a secure assessment** and cannot establish proficiency; qualified unseen forms and administration conditions need owner approval.
