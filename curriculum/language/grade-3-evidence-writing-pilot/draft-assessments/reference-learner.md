# Fixed reference tasks — learner (DRAFT, exposed, not secure)

Use [original fictional source A/B](../source-packet.md). Quote exactly with line labels or paraphrase without quotation marks; reason with the information given. These are **public exemplars**, not teaching-ready or independently administered assessment.

**S1.** Split *recheck* into prefix and base; explain its meaning in "Please recheck the route before using it." Can you infer the time of an earlier check?

**S2.** Split *careless* into base and suffix in "The careless note omitted a label." Explain the contextual meaning. Does Text A itself call Noor careless?

**S3.** Put in order with A labels: (a) add a checking reminder, (b) notice torn corner, (c) trace a route onto a new sheet.

**S4.** Classify: (i) Noor requested checking, (ii) they walked the route that day, (iii) the copied route was shown safe. Which are reported and which are not established? Cite the text.

**S5.** Quote a short A4 detail (with line label), or faithfully paraphrase it, supporting "the old map has information the copy lacks."

**S6.** Challenge Eli's "old map is useless" using one text detail. Say one thing the counterdetail does *not* prove.

**S7.** Calculate Monday's table count difference. Give two different nonnegative removal/addition combinations with the same net change. Why does B1 not prove exactly three borrowers?

**S8.** Calculate Tuesday's count change. Can B2–B4 tell the exact number of books returned to the bin? Explain.

**S9.** Revise "Noor verified the copied route by drawing it" into a bounded, attributed claim with A5 or A6. Identify the unsupported word.

**S10.** Give a three-sentence memo to a classmate who has not read Text A: introduce the map-copy question; include a faithful detail with an A label; give one limitation with a *second* A label. Indicate clearly if any words are exact quotations.

The teacher solutions and proposed rubrics are in a separate teacher-only reference.
