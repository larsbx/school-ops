# Lesson 3 — What a count table proves (teacher guide)

**Unit:** [U-MATH-001-06](../README.md) · **Status:** draft, not teaching-ready · **Outcomes:** 011 (supplied counts only), 006 · **Arts:** arithmetic and the table-representation component related to astronomical observation · **Pattern:** inquiry plus checked retrieval · **Proposed duration:** 25 minutes.

**Prerequisite:** independent E4 table interpretation and E2 composition; do not infer an astronomy observation skill from a supplied table. **Materials:** 3-row large-print/tactile table and tokens; fictional counts are clearly described as given task data, **not real sales, weather, or sky records**.

## Trivium and activity

**Grammar (5 min).** *Row*, *day label*, *recorded count*, *difference*, *total*, *prediction*. Ask what the table actually records and which days are *not* in it.

**Logic/model (8 min).** Supply a fictional library exchange table: **Mon 12 books**, **Tue 18 books**, **Wed 15 books**. Count all three: **45 books**; Tue − Mon = **6 books**. A claim “Thu definitely has 21 books” is **not supported**: a three-row table does not record Thursday and a pattern has not been justified. Distinguish “fictional recorded input” from real-world observation. If using a bar chart, keep one scale and label the counted unit.

**Guided (5 min).** A second fictional table contains **A 8**, **B 14**, **C 12** items. **Key: 34 items total**, B − A = **6 items**. The statement “D equals 10” is neither proved nor disproved by these rows alone; it is unrecorded.

**Independent exit (7 min).** [P3](../practice-learner.md#p3--table-and-claim) gives three new counts. Require table total, named units and a claim limited to actual rows. **Key: 7 + 11 + 9 = 27 recycled cards; middle minus first 4; the unlisted next day cannot be inferred.**

## Rhetoric, feedback and review

Learner says/draws/writes: “According to the supplied table, __; it does not establish __ because __.” A peer can locate each cited row. If the learner invents an unrecorded day, contrast a claim that is **in** the table with one that is **not** and use new rows. This lesson supplies **no genuine sky observation, lunar-cycle claim, astronomical source or recurrence evidence**; preserve the required astronomy-specific component for separate review.
