# Unit 3 — teacher diagnostic and guided practice key

**Draft / not approved.** Original questions (not retrieved or attributed to external providers). Pair with [learner-only prompts](practice-learner.md) and the [unit's readiness rules](README.md). Keep this key separate from student materials.

## Entry — independent evidence and remediation

| ID | Complete expected model/evidence | Gate |
| --- | --- | --- |
| E1 | 12 counters in either layout. Each is used once; rearrangement alone changes no total. | Count and explain 12, without double counting, before Episode 1; reteach with 6–10 if missing. |
| E2 | **4,4,4** is three equal groups (total 12); **5,4,3** has different sizes (also total 12), so it is not equal sharing. | Name equality of **sizes**, not merely equal totals, before Episodes 1–2. |
| E3 | 6 + 6 = 12; six disjoint pairs with zero leftover. | Model both part–whole and pairing before Episode 3; pairing alone is not division mastery. |

Do not average E1–E3 into a pass; record each unmet gate privately. Equivalent access responses are permitted. A supported or imitated result requires later fresh independent evidence.

## Episode 1 — keyed responses

| ID | Result | Required reason/model |
| --- | --- | --- |
| P1 | **3 groups, 4 counters each, total 12** | Three disjoint sets of four: 4 + 4 + 4 = 12. |
| P2 | **4 groups of 3**, then **3 groups of 4**; both total 12 | Each object used once, no addition/removal; different group counts and sizes, same amount. |
| P3 | **11** total, groups **4,4,3** are unequal | The last group is missing one to be “4 each”; 4 + 4 + 3 = 11, not 12. |

## Episode 2 — keyed responses

| ID | Result | Required reason/model |

## Teacher decisions and scope

For each prompt inspect **result/units**, **disjoint model**, **justification** and **communication**; one numerical result is not sufficient. Guided practice is *practice*, never a claim of independently demonstrated learning. Begin with the 0–12 route only if prerequisites support it; a modified item needs a separately checked key. Provide manipulative, tactile, read-aloud, oral, AAC or scribed support **without** suggesting the mathematical content. Use the [untimed six-item check](../../../../../assessments/C-MATH-001/equal-groups-sharing-teacher.md) for proposed independent evidence, but do not claim readiness until review and fresh form validation. No individual scores or names belong in this repository.
