# G4-L3 — Order, distance and movement on a marked number line

- **Unit:** [U-MATH-001-04](../README.md) · **status: draft** · **provisional 25 minutes**.
- **Art and outcome:** arithmetic with geometry; O-MATH-001-009.
- **Entry:** E1 comparison, E3 equal spacing; Unit 2 small-number composition/difference.
- **Materials:** tactile or large-print line with **13 equally spaced ticks labeled 0–12**; token for a moving marker.
- **Observable goal:** start at a given tick, make a stated number of *interval* steps forward/backward and state both endpoint and distance between two ticks.
- **Grammar:** tick, interval (space between adjacent ticks), number line, forward/backward, starting point, endpoint, distance.
- **Logic:** refute counting the starting tick as one move; explain why unequal spacing cannot represent equal unit distances.
- **Rhetoric:** communicate a repeatable instruction another learner can enact and check.

## Instruction and evidence

1. **Retrieve (4 min):** mark 2 and 5 on equal ticks and count three gaps 2→3→4→5. When uncertain, build equal-spaced strips.
2. **Model (6 min):** start at 4, take five forward *intervals* and arrive 9: 4→5→6→7→8→9. Mark each gap, not each label.
3. **Test (5 min):** start at 9, take six backward intervals to 3. Present the incorrect claim “count the starting tick as step one, so end at 4”; request counterexample by tracing gaps.
4. **Fade / partner reconstruction (5 min):** give “start 2, move forward 6, then backward 3”; partner traces to 5 with equally spaced unit steps.
5. **Independent exit (5 min):** [L3-X1](../practice-learner.md#lesson-exits) on a fresh line; check route and reasoning with [teacher key](../practice-teacher.md#lesson-exit-keys).

## Feedback

If correct endpoints occur by label counting, ask the learner to trace each *interval* and state why. If negative values or nonuniform tick spacing would be needed, resize the task; do not claim this unit taught signed numbers or coordinate geometry. A straight tactile number strip or AAC sequencing permits the same mathematical evidence.
