## Entry key

| Prompt | Complete model response and reason | Decision / remediation |
| --- | --- | --- |
| E1 | **8 counters; 8 > 6**. Six one-to-one pairs leave **2 extra counters** in the first group. | Require counting, comparison and a matched-pair reason; if absent, return to Unit 1/2 smaller-number route. |
| E2 | **6 tiles** in 2×3 and **6 tiles** in 1×6. Only the arrangement changes; no tiles are added or removed. | Must identify the fixed one-square unit and conserved count; if absent, revisit Unit 3 equal grouping (not yet assumed accepted). |
| E3 | Mark 2 and 5; count **3 gaps**: 2→3, 3→4, 4→5. Counting both endpoints as steps is incorrect. | If gaps are not equal, rebuild the line. Tactile traces or verbal steps satisfy the same criterion. |
| E4 | **6 short units** with six 1-unit rods end-to-end and no gaps or overlap. | A numeral without unit, or coverage with gaps, does not establish the entry condition. |

Full draft route requires **E1, E2, E3 and E4 individually**, with the modeled reason as well as the result. Keep “independent,” “supported,” “not yet” and “not assessed” distinct.

## Guided-task keys G1–G8

| Prompt | Correct answer and mathematical reason |
| --- | --- |
| G1 | 2×4 = **8 squares** and 4×2 = **8 squares**; rearrangement conserves the identical tiles. |
| G2 | 2×3 = **6 squares**; 1×6 = **6 squares**. Sam is wrong: different outlines can cover the same count of equal-sized unit squares. |
| G3 | **10 short rods** or **5 double rods** cover the same strip. Each double rod covers two short-unit spans. |
| G4 | Three double rods cover **6 short units**, leaving a **2-short-unit gap**. Add the fourth double rod flush with the others and the endpoint; then **4 double rods = 8 short units**. |
| G5 | 3→4→5→6→7 = **7**, four intervals. The start label is not a step. |
| G6 | 10→9→8→7→6→5 = **5**. From 4 to 9 lie **5 intervals**: 4→5→6→7→8→9. |
| G7 | Each side is 2×3 = **6 equal squares**, so both shares have the same square-unit count. Total **12**. |
| G8 | After column 1: **3** squares on the left and **9** on the right; unequal. “Two parts” by itself does not imply equality. |

## Lesson exit keys

| Exit | Full model response; what to inspect |
| --- | --- |
| L1-X1 | 4×2 = **8** equal squares; 1×8 = **8** equal squares. Outlines differ, square counts match. Counterexample disproves the general claim. Require count, same unit size and explanation. |
| L2-X1 | **5 double rods** cover the 10-short-unit strip; **10 short rods** also cover it. No gaps/overlaps; each double rod spans two short units, hence fewer rods for the same length. Require *both* numbers with named units and inverse-size reason. |
| L3-X1 | Start 5→6→7→8→9 (4 forward), then 9→8→7 (2 backward): final **7**. From 2 to 7: **5 gaps** (2→3→4→5→6→7). Require movement as intervals and distance with equal tick spacing. |
| L4-X1 | Divider after column 2: left 2×2 = **4**, right 2×4 = **8**; not equal. Move it after column 3: left **6**, right **6**. Equal-size tiles establish equal square counts; total **12**. |

## Administration, feedback and safeguards

1. Teach with one set of tiles, then **cover worked examples and keys** before independent exits. A teacher's hint requiring a missing number/reason is *supported*, not independent.
2. Accept verbal, tactile, pointer, large-print or scribed representation if all mathematical distinctions remain available. A scribe records the learner's actual words, not a suggested answer.
3. Record each criterion separately: correct count/measure, correct units and a checkable reason. Revise the targeted misconception and retest with different arrangement, length, movement or partition.
4. Do not declare O008/009/012 met from single guided examples. Independent reference assessment needs unexposed alternatives and owner review of tasks, tools, criteria, exposure and teaching time.
5. No external sources or private learner records are incorporated. This original authored material requires pedagogical and accessibility review; it does not imply use rights for any later imported diagrams or media.
