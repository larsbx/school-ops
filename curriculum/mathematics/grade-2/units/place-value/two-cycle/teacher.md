# M01 — Teacher guide and complete key

- Implements: [L-MATH-001-01-01](../lessons/01-tens-and-ones.md)
- Learners: 2nd grade; PV2 scope, 0–99
- Status: draft; readiness review pending
- Evidence: O-MATH-001-001, tens/ones component only
- Materials: at least 99 counters or base-ten equivalents, ten-bundles/chart,
  paper, pencil, separate learner/workbook copies and one partner card each
- Access: read directions aloud; allow objects, drawing, pointing, spoken
  explanations and an adult scribe; no reading-speed or spelling criterion

Use the existing entry check and count twelve counters one-to-one before
starting. Confirm the same kind of counter is the one-unit throughout an
exchange. If counting is insecure, return to a smaller collection; do not
silently rewrite the fixed pilot and call it reviewed.

## Cycle A — Build and describe

| Stage | Action | Planned minutes |
| --- | --- | --- |
| Entry/retrieval | Count twelve and name the one-unit | 3 |
| Model | Group fourteen counters into one ten and four ones; show all fourteen are retained | 5 |
| Guided work | A1 and A2; have the learner point to the counted units | 7 |
| Partner exchange | A3 using separately distributed cards; swap describing/reconstructing roles | 7 |
| Exit | A4, with a model and conservation reason | 3 |

Original modeled exchange: Teacher: “These fourteen counters are our amount.
I put ten in one group. What stayed the same?” Partner: “All fourteen counters
are still here.” Teacher: “What do we call that group?” Partner: “One ten.”
Ask the learner to demonstrate why the statements are true, rather than
memorizing the dialogue.

A2 script, read one collection at a time without showing this guide:
“Build three tens and four extra ones.” Then: “Build six tens with no extra ones.”
The read-aloud description is the input, not an answer cue. Additional help in
interpreting a unit or choosing a group is support and should be recognized as such.

## Cycle B — Exchange and explain

| Stage | Action | Planned minutes |
| --- | --- | --- |
| Retrieval | Rebuild A4 and name the grouped units | 3 |
| Model | Start with 21 as 2 tens + 1 one; unpack one ten into 10 ones, leaving 1 ten + 11 ones | 5 |
| Guided work | B1 and B2; test the false claim physically | 7 |
| Partner exchange | B3 with the second section of the separate cards | 7 |
| Exit | B4; seek the amount-preservation explanation | 3 |

An unpacked ten becomes ten individual ones. Do not remove a ten without adding
its ten ones, count a bundle as a single one, or add a ten and its contents to the
same model. Packing is the reverse change. Make all stages inspectable.

| Task | Exact result/model | Required reason or observation |
| --- | --- | --- |
| Opening model | 14 = 1 ten + 4 ones | Ten of the original one-units make the grouped ten |
| A1 | 16 = 1 ten + 6 ones | Grouping retains all sixteen counted units |
| A2, first | 34 = 3 tens + 4 ones | Correct reconstruction from named units |
| A2, second | 60 = 6 tens + 0 ones | Zero means no extra single ones beyond the tens |
| A3, red/card A | 24 = 2 tens + 4 ones | Partner's model agrees with the stated groups |
| A3, blue/card B | 50 = 5 tens + 0 ones | No extra ones; fifty ones are contained in the five tens |
| A4 | 27 = 2 tens + 7 ones | Identify a single counter as the one-unit; grouping preserves 27 |
| B1 | 32 = 3 tens + 2 ones = 2 tens + 12 ones | One ten is replaced by ten ones |
| B2 | Claim false: 43 = 4 tens + 3 ones = 3 tens + 13 ones | The proposed 3 tens + 3 ones gives 33 and loses ten |
| B3, green/card A | 1 ten + 16 ones = 2 tens + 6 ones = 26 | Pack ten of the sixteen ones; all 26 remain |

A partner's agreement is feedback, not proof of correctness. Check the actual
reconstruction and named units. For a single learner, the teacher holds the
other card and models the recipient role; no peer access is required.

Accept equivalent accurate models and spoken explanations; correct a unit name
when it makes the mathematical meaning wrong. No particular sentence form is
required. These tasks rehearse components of outcome 001 and do not certify
outcomes 002–004.

## Evidence and next step

A4/B4 exits: require correct unit labels, an accurate model and a conservation
reason the recipient can follow. If the answer is correct but the reason is
missing, ask for a demonstration and treat any teaching prompt as support.
For unit/amount confusion, return to the physical one-unit and a ten-group.
For zero confusion, contrast a collection of tens with an empty collection.
For an exchange error, preserve the full collection and reverse the exchange.

Core sessions total 50 planned minutes and replace the usual 25-minute lesson.
Optional workbook blocks total another 10–16 minutes; the separate
[formative review](../../../../../../assessments/C-MATH-001/tens-and-ones-cycle-review.md)
plans another 5–10, with flexibility. Review time is not a speed threshold.
Use the outcome judgment to plan review or the selected next lesson; the PV3
route still needs lesson 2. The pilot alone does not establish hundreds,
counting sequences, number-form conversions or comparison outcomes.

Keep the guide and review key out of learner view. Published/practiced tasks
require fresh keyed applications before independent assessment claims.
Individual learner evidence remains private.
