# M01 pilot — Groups keep the amount

- Course/unit: [C-MATH-001 / U-MATH-001-01](../README.md)
- Implements: [L-MATH-001-01-01](../lessons/01-tens-and-ones.md)
- Intended learners: 2nd grade; selected PV2 tens/ones scope, 0–99
- Status: draft
- Primary art: arithmetic
- Outcome component: O-MATH-001-001, tens/ones grouping, exchange and zero ones
- Design: [two-cycle course](../../../course-design.md)
- Readiness review: pending; no learner use or delivery timing claimed

This pilot supplies an alternative implementation of the first lesson using
original materials. It replaces the usual 25-minute implementation with two
25-minute sessions. It does not replace the whole first unit, the hundreds
lesson, or A-MATH-001-02. Do not append it to the original lesson as unseen extra
work. A teacher may act as the partner for a single learner.

## Two cycles and materials

| Cycle | Relationship | Communication goal | Materials |
| --- | --- | --- | --- |
| A | Ten counted ones can form one ten; zero ones is meaningful | Describe groups so a partner can reconstruct them | [Learner book](learner.md) A1–A4; separately distributed [card A](partner-card-a.md) and [card B](partner-card-b.md) |
| B | Packing and unpacking equal-valued groups preserve amount | Explain an exchange and test a mistaken claim | Learner book B1–B4; second section of the partner cards |

Teacher preparation and all keys are in the [teacher guide](teacher.md).
The [workbook](workbook.md) supplies W1–W8. The separate formative review
[A-MATH-001-04](../../../../../../assessments/C-MATH-001/tens-and-ones-cycle-review.md)
has its own [learner copy](../../../../../../assessments/C-MATH-001/tens-and-ones-cycle-tasks.md).
Distribute only the relevant learner pages/card. Keep the teacher guide and
assessment key out of learner view; public navigation is not an assessment interface.

## Entry, budget and evidence

Use the existing entry check first. For this implementation, confirm the child
can count twelve counters one-to-one and identify one counter as the counted
unit. If not, return to smaller collections before using this fixed-range pilot;
a smaller-range revision needs actual authored tasks and a key.

Core instruction: 25 + 25 = 50 proposed minutes. Workbook: two optional
5–8-minute blocks outside the core sessions, one after each cycle. Formative
review: another 5–10 minutes, with extra time or split sittings allowed.
The unit's expanded route adds 25 core minutes to its usual estimate.
These budgets are proposals, not deadlines or a dated weekly plan.

Use local exit evidence from A4/B4 to decide the next activity. Correct naming
(grammar), conservation reasoning (logic), and an explanation a partner can
follow (rhetoric) are all required. The review checks only the tens/ones component
of outcome 001. It does not establish all of 001–004, hundreds readiness or PVX.
