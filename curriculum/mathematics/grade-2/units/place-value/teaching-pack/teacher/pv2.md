# PV2 teacher route - tens and ones

Grade 2 • C-MATH-001 / U-MATH-001-01 • draft • range 0–99

Sequence: M01 A/B (-01), number forms (-03), counting (-04), comparison (-05),
unit check (-06). L-MATH-001-01-02 is intentionally deferred. Core estimate:
50 + 25 + 25 + 25 + 25 = 150 minutes, plus entry and optional work stated below.
The route establishes only two-digit components; hundreds and PVX remain pending.

## Administration and evidence contract

Start with A-MATH-001-01 (10–15 additional minutes), using its separate learner
sheet and item-specific criteria. Verify M01's twelve-counter prerequisite.
State the route from actual entry and lesson evidence, not grade alone.
No learner result or actual pace is assumed. Use the pack materials checklist;
establish the amount represented by each grouped object before using it as a token.

The sequence uses M01 two-cycle communication, then worked-example fading in
number forms, retrieval and concrete boundary modeling in counting, and a
claim/counterexample investigation in comparison. Complete models come before
supported attempts and blank independent sheets. Fading removes solution cues,
not manipulatives, read-aloud, scribing or explanation criteria. A teacher can
be the partner; no compulsory online practice or peer availability is assumed.

For lessons 2–5 use 3 minutes retrieval, 5 modeling, 7 guided practice, 7 independent
work and 3 exit/check. Split or extend when needed. Independent sheets revisit
some guided claims for practice; these are formative, not fresh summative evidence.
Give substantive help when needed and recognize the resulting work as supported.
All prompt parts have keys below or in the explicitly linked M01/assessment key.
These are authoring estimates, not a calendar or a required performance speed.

## Lesson 1 - L-MATH-001-01-01 using M01

Outcomes: O-MATH-001-001 tens/ones component; preparatory 002–003.
Prerequisite: count twelve counters one-to-one, name one counter as one-unit.
Materials: enough counters/base-ten equivalents for 99, blank Tens/Ones chart,
separate partner cards, paper and pencil. Primary art: arithmetic grouping.

Use the merged [M01 teacher guide](../../two-cycle/teacher.md) with its unchanged
[learner book](../../two-cycle/learner.md), [workbook](../../two-cycle/workbook.md)
and separate cards. Its scripts and complete A1–B4, W1–W8/card keys are authoritative
and included in the teacher print edition. Cycle A models 14, reconstructs groups,
and ends with 27; Cycle B unpacks 21 and ends with two models of 46. Grammar names
the counted one-unit and grouped ten; logic conserves the collection; rhetoric
asks a partner to reconstruct and inspect the explanation.

Use A4/B4 criteria: accurate amount and labels, conservation reason and explanation
another person can follow. Failure to count requires smaller collection instruction;
unit confusion requires opening a ten; zero confusion requires contrasting grouped
tens with an empty collection. Continue only after evidence in this component.
Do not read this as whole outcome-001 success. The optional A-MATH-001-04 review
has four tasks and a separate teacher key, linked in the pack and included in print.
Core time is 25 + 25 = 50; workbook 10–16 and formative review 5–10 are additional.

## Lesson 3 - L-MATH-001-01-03: number forms

Outcomes: O-MATH-001-003; review 001. Prerequisite: show tens/ones, zero ones and
a conserving exchange in M01. Materials: tens/ones objects, blank chart, paper,
pencil and [learner sheet](../learner/pv2-03.md). Primary art: arithmetic representation.

Retrieval: model 40 and explain the zero. Model 57 with five tens and seven ones;
write 50 + 7 and say "fifty-seven," pointing between each form. Guided work: convert
60 and 68; test "the 6 in 68 means six single ones" using actual groups. Remove the
worked answer before independent work. Use sheet items 01–03 for seven minutes;
item 04 is the exit. Grammar distinguishes digit, numeral, name and expanded form;
logic tests a unit mismatch; rhetoric connects all representations for a listener.

### Complete lesson and learner key

Retrieval: 40 = 4 tens + 0 ones, forty. Model: 57 = 50 + 7, fifty-seven.
Guided: 60 = 6 tens + 0 ones, sixty; 68 = 6 tens + 8 ones = 60 + 8,
sixty-eight. Six ones have value 6; six tens contribute 60.

- P-PV2-03-01: 39, thirty-nine, 30 + 9; 3 tens and 9 ones. All forms represent 39.
- P-PV2-03-02: 60, sixty; 6 tens and no extra ones. Zero does not erase the sixty ones inside the tens.
- P-PV2-03-03: claim false; 68 has six tens, contributing 60, plus 8 ones. A model of six ones and eight ones would show 14, not 68.
- P-PV2-03-04: eighty-two; 80 + 2; 8 tens contribute 80. The zero term convention does not apply to a nonzero ones position.

Success check: all corresponding models, names and sums agree; explain the tens
contribution and zero position. Accurate spoken names suffice without independent
spelling. If not, restore objects and the chart. Progress to counting when the
amount-to-place connection is inspectable; keep unfinished parts for review.

## Lesson 4 - L-MATH-001-01-04: repeated steps and tens boundary

Outcomes: O-MATH-001-002; review 001/003. Prerequisite: read the route values and
connect them to tens/ones. Materials: objects, blank chart, paper, pencil and
[learner sheet](../learner/pv2-04.md). Primary art: arithmetic repeated addition.

Retrieve 38 through 42, including both endpoints. At 39 add one: three tens and
ten ones, then exchange ten ones for one ten, giving 40. Model four terms by tens
from 20. Guided work: five terms by fives from 25; add five actual ones each time,
then pack complete tens. State that the starting value is the first term.
Use sheet items 01/04 independently; items 02/03 provide the exit and explanation.
Grammar defines start, step and term; logic checks constant differences and
conservation after addition; rhetoric teaches the counting rule with the models.

### Complete lesson and learner key

Retrieval: 38, 39, 40, 41, 42. Model: 20, 30, 40, 50; add one ten each time.
Guided: 25, 30, 35, 40, 45; add five ones, preserving each new amount when packing.

- P-PV2-04-01: 55, 60, 65, 70, 75; step five.
- P-PV2-04-02: 58, 59, 60, 61, 62. Before: 59 = 5 tens + 9 ones. Add one to obtain 5 tens + 10 ones; exchange to 6 tens + 0 ones = 60. Addition increases the amount; the exchange preserves 60.
- P-PV2-04-03: 46, 56, 66; add one ten, with the six ones unchanged.
- P-PV2-04-04: corrected 25, 30, 35, 40, 45. The proposed steps are 5, 6, 4, 5, so they are not all five.

Success check: all terms and endpoints correct, starting value counted, step
identified, boundary model and conserving exchange explained. If recitation is
correct but the model is not, return to the objects before progression. Never
introduce 100 on this route merely because the source lesson has larger examples.

## Lesson 5 - L-MATH-001-01-05: comparison

Outcomes: O-MATH-001-004; review 001/003. Prerequisite: read and model two-digit
amounts. Materials: objects, blank chart, paper, pencil and
[learner sheet](../learner/pv2-05.md). Primary art: arithmetic order.

Retrieve 24 and 42 with models. Model 35 and 53, matching tens before inspecting
ones. Guided work: 90 versus 49 and 66 versus 66. Explain that nine tens exceed
four tens even though zero ones is less than nine ones. Use sheet items 01/04
for independent work; 02/03 for exit. Grammar reads the whole symbol statement;
logic tests the irrelevant-digit argument; rhetoric presents claim, unit and reason.

### Complete lesson and learner key

Retrieval: 24 = 2 tens + 4 ones; 42 = 4 tens + 2 ones.
Model: 35 < 53 (3 tens < 5 tens). Guided: 90 > 49 (9 tens > 4 tens);
66 = 66 (same 6 tens and 6 ones).

- P-PV2-05-01: 19 < 29 < 91; tens are respectively 1, 2 and 9.
- P-PV2-05-02: 57 < 75; five tens are less than seven tens. Read "fifty-seven is less than seventy-five."
- P-PV2-05-03: 82 > 78; eight tens exceed seven tens.
- P-PV2-05-04: 66 = 66. The claim about 90 is false: 90 > 49; the tens place differs first and controls the order. The ones comparison cannot override it.

Success check: each symbol agrees with the named relation and an inspectable
place-value reason or equality model. Restore matched models for irrelevant-digit
reasoning. Use the normative PV2 form in lesson 6 only after all route relationships
have been taught; numerical fluency alone is insufficient.

## Lesson 6 - L-MATH-001-01-06: selected-route evidence

Outcomes: O-MATH-001-001–004 within the taught route. Materials: selected learner
form, working paper, counters/base-ten blocks, blank chart; no calculator.
Prerequisite: the route's preceding lesson models and explanations, or equivalent
privately documented evidence. Do not assess PVX without its separate instruction.

Retrieve unit names and symbols for 3 minutes without exposing assessment answers.
Distribute only the selected A-MATH-001-02 learner form. Allow 15–20 minutes,
extra time or split sittings. Complete a 2-minute teach-back if useful, but inspect
all requested reasons during the assessment, not only that final sample.
No speed threshold applies. Teacher print editions include the full existing
assessment key; do not distribute those editions to learners.

Read directions without answer cues; accept speech, drawing, pointing and scribing.
Accept customary "and" in number names and omit zero terms in sums if accurate.
Record substantive teaching prompts as support. Every subpart must meet its
outcome criterion: model/units/exchange/zero in items 01–03 plus composition in
04; all sequences, steps and boundary reasons in 04–06; conversions and model
connection in 07–09; comparison symbols and place-value reasons in 10–12.
A recited sequence alone does not establish the conservation criterion in item 04.
Addition changes the amount; subsequent equal-valued exchanges conserve the new amount.

Grammar checks names and notation; logic checks invariant/step/comparison reasons;
rhetoric checks whether the explanation connects claim, model and reason for another
person. Inspect independently / supported / needs review / not assessed per outcome
and taught scope privately. Do not sum these into a course pass mark.

Use a fresh inspected bank 1.0.1 conceptual form when full applications were practiced
or keys exposed. Changing seeds alone does not establish freshness. Keep manifests
and all keys separate. Timed bank drills remain optional fluency work outside the
core instruction/assessment budget, and never replace model/reason evidence.

## Follow-up decisions by relationship

| Evidence gap | Revisit | Fresh application / next decision |
| --- | --- | --- |
| One-unit, grouped unit or reverse exchange (001) | M01; PV3 also lesson 2 | Open and repack equal-valued groups; show each stage with a different amount before continuing |
| Zero position (001/003) | M01 zero ones; PV3 lesson 2 zero tens | Contrast an empty position with an empty collection; name remaining groups |
| Boundary or repeated step (001/002) | Lesson 4 objects and chart | Add the one or grouped step first, then conserve that new amount through exchanges; check a different boundary |
| Name, numeral or sum mismatch (003) | Lesson 3 concrete-to-symbol connection | Use a new keyed amount and connect each place to its unit; spelling support remains available |
| Irrelevant digit used for comparison (004) | Lesson 5 matched higher places | Build two fresh keyed amounts; inspect the first differing place or equality |
| Correct result without model/reason | Relevant lesson explanation task | Ask for a demonstration; recognize teaching prompts as support and recheck afterward |

Proceed in the checked scope only after every part of the relevant outcome group
is accurate with its model and reason. Supported evidence informs teaching; obtain
fresh independent application before calling that relationship independent. Keep
unassessed content pending. No duration, confidence rating or exercise count proves
understanding. Private records include route/form ID, support, outcome judgments and
follow-up; the shared repository receives only curriculum changes.
