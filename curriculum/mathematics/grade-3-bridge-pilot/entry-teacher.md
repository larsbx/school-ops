# Grade 3 arithmetic bridge — teacher-only entry key (draft)

This guide is **not for distribution with learner pages**. Original authoring exemplars only; it contains no learner observations. Never infer readiness from age, course labels, completed code tests or previous Grade 2 PR merges. Provide accessible oral, drawn, tactile or assistive output without changing the target relationships.

| Entry | Complete model answer and reasoning | Proposed gate / remediation |
| --- | --- | --- |
| E1 | **470 = 4 hundreds + 7 tens + 0 ones = 400 + 70 + 0**. Final zero indicates no units of one, **not** zero value for the whole quantity. | Correct quantity, zero-place interpretation and justification. If not, rebuild two- and three-digit tens/ones with bundles and check a different number (e.g., 508). |
| E2 | **3 × 5 = 15** counters, three groups of five; 3 + 5 = 8 mixes number of groups with size per group. | Must show 3 equal groups **and** their total. If not, physically sort 2 groups of 4 and retry with 4 groups of 3. |
| E3 | **12 ÷ 4 = 3** per box. Four equal groups of 3 consume all 12 (4 × 3 = 12), remainder 0. | Both equal allocation and a check required. If not, share 8 across 2 before retrying with 15 across 3. |
| E4 | **8 ÷ 4 = 2** identically sized cells in each of four parts. The suggested groups 1, 2, 2, 3 are unequal even though they sum to 8. | Four same-area two-cell parts with a reason. If not, build an 8-cell, 2-by-4 rectangle and group into adjacent two-cell strips; retry with 12 cells in four parts. |

**Branching decision:** E1 precedes lesson 1, E2 and E3 precede lesson 2, E3 and E4 precede lesson 3. An E1 failure does not automatically bar non-place-value investigations when their own prerequisites are independently demonstrated; do not infer readiness for a different component. Report each outcome as *demonstrated on entry*, *not yet shown*, or *not assessed* privately. No averaged pass mark and no learner names in Git.

**Review blockers:** approve number ranges, manipulation materials, language and accessibility supports and actual timetable; confirm that E4's use of equal-area cells is appropriate for intended learners. The check is **draft**, not an adopted placement rule.
