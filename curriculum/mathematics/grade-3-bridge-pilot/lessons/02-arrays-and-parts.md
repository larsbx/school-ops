# Episode 2 — Arrays, factors and splitting the rectangle (teacher-only draft)

**Status:** DRAFT, not ready. **Local goal:** `G3M-P2`. **Primary art:** arithmetic; geometry supplies an equal-square representation, not a separately assessed course. **Prerequisites:** E2 equal groups and E3 fair sharing shown independently. **Materials:** at least 32 identical square tiles or tactile/large-print array grid; no compulsory device. **Proposed time:** 25 min.

| Activity | Minutes |
| --- | ---: |
| Grammar of rows, columns and equal-sized cells | 4 |
| Logic/model with split arrays | 8 |
| Guided example and fading | 6 |
| Rhetoric / independent exit | 5 |
| Feedback/retry | 2 |
| **Total** | **25** |

**Grammar (4):** A **row** travels across, a **column** goes down. An array of 3 rows with 8 cells in each row contains 3 × 8 cells; do not conflate *three rows* with *eight columns*. Each tile denotes one count; a split must not duplicate or omit tiles.

**Logic/model (8):** Lay out **3 rows × 8 cells = 24 cells**. Split every row after the fifth cell: left section 3×5 = 15; right 3×3 = 9; 15+9 = **24**. Preserve the original rectangular set: **3×(5+3) = 3×5 + 3×3**. Ask why “3×8 = 3+8” fails (11 ≠ 24); point to three actual groups of eight.

**Guided (6):** Learner constructs 4×7, then marks columns **2+5**. Give the first 4×2=8 model; with fewer prompts obtain 4×5=20 and total **28**. Verify 4×7=28 without counting the two joining columns twice. A rotated 7×4 layout can have the same count of 28, but no claim that the row labels are unchanged under rotation.

**Rhetoric / exit X2 (5):** On an unmarked grid, show **five rows of six** split as four columns plus two columns. Learner states **5×6 = 5×4 + 5×2 = 20 + 10 = 30**, marking the partition so another learner can count disjoint cells. A correct number "30" without an actual split/equality is **not yet** `G3M-P2` evidence.

**Feedback (2):** If learner writes 5×(4+2)=20+2, use physical rows to show why each right-hand column still has five cells. Reassess later with 3×7 split as 3×(2+5)=6+15=21. Do not supply an answer to X2 during assessment; the above is a teacher model.
