# Episode 1 — Four-place numbers and a zero place (teacher-only draft)

**Status:** DRAFT, not ready. **Local goal:** `G3M-P1`. **Primary art:** arithmetic; **Trivium:** grammar of thousands/hundreds/tens/ones, logic of comparing at the first differing place, rhetoric of a checkable bundle or diagram explanation. **Proposed time:** 25 min. **Prerequisite:** E1 shown independently; otherwise use the remediation in [entry key](../entry-teacher.md). **Materials:** movable labeled bundles/place-value cards or large-print/tactile equivalent. No external licensed materials required.

| Activity | Minutes |
| --- | ---: |
| Retrieve and name units | 4 |
| Model and challenge a false claim | 7 |
| Guided representation with fading | 6 |
| Independent exit, explain and check | 5 |
| Feedback and adaptive retry | 3 |
| **Total** | **25** |

**Grammar (4):** Name one thousand as 10 hundreds, one hundred as 10 tens; each rightward unit is ten times smaller. Demonstrate that a position with zero *units of that place* still holds its place. Learner states what the 0 in **3,042** means.

**Logic (7):** Build **3,042 = 3×1000 + 0×100 + 4×10 + 2** with labels. Compare **3,042 and 3,240**: thousands tie; hundreds 0 < 2, so 3,042 < 3,240. Challenge: “3,040 is greater than 3,400 because 40 is bigger than 4.” Reject: hundreds 0 < 4. The words "40" and "4" cannot be compared while ignoring places.

**Guided and fading (6):** With a shown place-value frame, learner composes **4,105 = 4,000 + 100 + 0 + 5**, then represents **4,015 = 4,000 + 0 + 10 + 5** without the model. Ask which is larger and why: 4,105 > 4,015 by the hundreds place (1 > 0). If an unexplained digit swap occurs, build only the differing places with bundles.

**Rhetoric / independent exit X1 (5):** Explain or build **2,307 = 2 thousands + 3 hundreds + 0 tens + 7 ones** and compare with **2,370**. Model answer: 2,307 < 2,370 because the tens differ, 0 < 7 after matching thousands and hundreds. Accept speech, a labeled drawing, braille or an assisted transcription; the adult cannot supply the place labels.

**Feedback/retry (3):** Correct numeral alone is insufficient for `G3M-P1`. If a zero is dropped, reconstruct 2,307 with an empty tens pocket and a distinct 2,370 example; then reassess with a new pair, not X1 reused. The final unit reference tasks [S1–S3](../draft-assessments/reference-learner.md) are fixed exposed exemplars, not secure measurement of independent mastery.
