# Four actual draft teaching episodes

**Proposal only / not ready.** These 25-minute blocks illustrate lesson design; time and access are not approved. Same-sized strip cells represent the **same whole** except when the question explicitly changes length. Use the [teacher key](teacher-guide.md) for X1–X4.

## Episode 1 — A fraction is of a whole (E1, E2; P1, P4)

| Trivium phase and original teacher/learner action | Minutes |
| --- | --- |
| Grammar: name whole, numerator, denominator and equal part on 12-cm quartered strip | 5 |
| Logic: compare 1/2 of 12 cm with 1/2 of 8 cm by measuring 6 and 4 cm, challenge “all halves have equal length” | 8 |
| Guided: sort correct “half of 12 is 6,” false “half of 8 is 6,” and invalid “three unequal cells prove thirds”; explain each | 7 |
| Rhetoric / **X1**: explain half of 10 cm versus half of 6 cm; report lengths and the false whole assumption | 5 |

**Feedback:** when a learner says “both halves so equal”, ask “half of what?” and repeat with a new pair of strip lengths.

## Episode 2 — More pieces, same shade (E3; P2)

| Trivium phase and original teacher/learner action | Minutes |
| --- | --- |
| Grammar: identify half, fourth, eighth using a fixed eight-cell strip | 5 |
| Logic: shade four cells and regroup as one half, two fourths, four eighths; test the claim that cutting increases shade | 8 |
| Guided: prove 3/4=6/8, reject 3/4=3/8 by counting the same cells | 7 |
| Rhetoric / **X2**: on a 12-cell whole shade 1/3, rename in sixths, explain retained amount | 5 |

**Feedback:** keep the actual strip and shaded cells fixed while changing only partition grouping.

## Episode 3 — Add common parts (E4; P2, P3)

| Trivium phase and original teacher/learner action | Minutes |
| --- | --- |
| Grammar: read common unit and equivalent fraction correctly on one strip | 5 |
| Logic: contrast false 1/2+1/4=2/6 with 2/4+1/4=3/4 by covering fourths | 8 |
| Guided: on eight cells show 3/8+1/4=5/8 and 3/4−1/8=5/8, naming converted parts | 7 |
| Rhetoric / **X3**: use six cells to explain 2/3+1/6 and rebut denominator addition | 5 |

**Feedback:** reject the mixed-unit rule through a specific cell count, not by reciting a new algorithm.

## Episode 4 — Repair a false rule (E1–E4; P1–P4)

| Trivium phase and original teacher/learner action | Minutes |
| --- | --- |
| Grammar: retrieve same whole, equivalent fraction, counterexample | 5 |
| Logic: use 2/3+1/3=1 on thirds, then test comparing half a short strip with one-third a long strip | 8 |
| Guided: recut a ten-cell whole to repair 2/5+1/10=3/15 and explain why 3/15 fails | 7 |
| Rhetoric / **X4**: compute 1/2+3/8 on one eight-cell whole and refute 4/16 | 5 |

**Feedback:** diagnose wrong whole, unequal parts, conversion, calculation or explanation, then teach and reassess that particular gap with new numbers.
