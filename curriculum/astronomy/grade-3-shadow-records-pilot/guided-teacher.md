# Guided tasks G1–G8 and lesson exits X1–X4 — teacher key (DRAFT)

Separate from [learner sheet](guided-learner.md); fixed examples are visible in Git, so they are not independent mastery assessments. The values are fictional, not external observational sources. All suggested criteria require pedagogical review.

| Item | Fully worked model | What to do with a misconception |
| --- | --- | --- |
| G1 | Measure from the **stake/base–ground contact** to the **shadow-tip endpoint**, along the same ground surface, in **centimetres**. Keep stake height, upright position, same ground measurement origin, apparatus and site fixed; record clock label and conditions. | Have learner mark the zero and endpoint on a drawing and name units. |
| G2 | **No**. Different stake heights (20 cm vs 40 cm) confound comparison. Values 17 and 24 cm cannot isolate a time effect, especially at the same 10:00 label. | Ask which variable changed; redraw equal-height examples. |
| G3 | Descending: **32, 27, 12 cm**. 32−12 = **20 cm**; 27−12 = **15 cm**. Lowest among three samples = **12 cm at 12:00**. | Mark each value on 0–40 line, do two subtractions, revisit sample qualifier. |
| G4 | Three points at (09:00, 32 cm), (12:00, 12 cm), (15:00, 27 cm); horizontal **clock time, 3 hours/tick**; vertical **shadow length in cm, 10 cm/tick**. A graph must not interchange units or shift scale. | Plot 30 and 10 first; then locate values between gridlines. |
| G5 | The noon value is **unknown**, not zero. Do **not** plot (12:00, 0) or treat an interpolated value as observed. Leave absent measurement explicitly marked missing. | Contrast measured zero, missing data, and drawn interpolation on neutral tables. |
| G6 | Different heights **20 vs 40 cm** confound. Keep an identical stake at fixed site/position and measuring method before interpreting a time comparison; note matched times still cannot prove cause. | Separate apparatus variables from time labels; never infer actual Sun position from hypothetical records. |
| G7 | “Among three values, 12:00 recorded **12 cm**, the lowest.” A different unmeasured time could be even lower. The all-day minimum is **not established**. | Make a fourth hypothetical time to demonstrate logical possibility without inventing a real measurement. |
| G8 | B at 09:00 is **2 cm lower** than A (32−30); B at 12:00 is **1 cm lower** (12−11). Both matched **recorded** B values are lower. Cannot conclude B lower at every time, establish cause, or verify actual astronomy. | Keep quantifier restricted to these entries; request independent records for generalization. |

## Lesson exits and component check

| Exit | Complete answer / required evidence |
| --- | --- |
| X1 | 18−12 = **6 cm**; moving stake changes setup/site/origin, so comparison lacks the fixed-position control; fix the stake and origin at the same site and measure again. All three components required. |
| X2 | Of the three fictional samples, **12 cm at 12:00** is lowest; 27−12 = **15 cm**; unknown intermediate times mean it is **not** proven shortest all day. All three independent claims needed. |
| X3 | Plot A: (09:00,32), (12:00,12), (15:00,27), horizontal 3-hour time ticks, vertical 10-cm length ticks; **B at 12:00 = not recorded**, never zero or fabricated. |
| X4 | At matched **09:00** sample B is **2 cm shorter** than A (30 vs 32 cm). “Always shorter” is not supported: B has **no 12:00 reading** and other times unmeasured. Collect comparable missing-time and additional controlled readings before broader claim. |

**Proposed noncompensatory progression:** P1 demands method/units; P2 correctly labelled axes and preserved unknowns; P3 correct subtractions with comparability qualification; P4 correctly bounded written, oral or AAC reasoning. If one is absent, teach that component and reassess on a fresh, teacher-created number set rather than average the results. A correct number without appropriate scientific limitation is not a complete proof. Speech, large type, raised axis and scribing are accepted when they express equivalent content; do not mark accessibility requests incorrect.
