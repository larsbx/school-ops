# R1–R10 complete teacher reference key and candidate rubric (draft)

The [learner reference form](reference-learner.md) is publicly exposed. **No fresh assessment, classroom readiness, independence, mastery or learner scores can be claimed from it.** Original figures use conceptual unit squares, not external sources.

| Task | Complete answer and justification | Goal |
| --- | --- | --- |
| **R1** | 2×3 has **area 6 square units**, perimeter **10 length units**: 3+2+3+2. Seven shared edges are internal. | P1/P2 |
| **R2** | 1×4 has **area 4 square units**, perimeter **10 length units**: 4+1+4+1. | P2 |
| **R3** | L shape has **area 5 square units** (2+3), **perimeter 10 length units**. Five shared sides (1 top horizontal +2 bottom horizontal +2 vertical) remove 10 from 4×5=20 edges. Outside walk: 2+1+1+1+3+2=10. | P1/P2 |
| **R4** | 1×6 has **area 6 square units**, perimeter **14 length units**: 6+1+6+1. R1 also area6; its boundary10 is smaller. | P2/P4 |
| **R5** | Filled 3×3 has **area 9 square units**, **perimeter 12 length units**: 3+3+3+3. | P2 |
| **R6** | Counterclockwise from east: northeast **less** than right angle; north **equal** (the square corner); northwest **greater**. | P3 |
| **R7** | **False**: a ray's lengthening without changing vertex/direction does not change opening; hinged strips can extend while fixed in orientation. | P3 |
| **R8** | R1 perimeter10 and area6, R2 perimeter10 and area4. Equal perimeters, unequal areas, so **false**; explicit counterexample. | P4/P1 |
| **R9** | R1 area6/perimeter10, R4 area6/perimeter14. Equal areas, unequal perimeters, so **false**; explicit counterexample. | P4/P2 |
| **R10** | **6 length units**, because 4+4−2=6; the one shared edge is counted twice in 4+4 but is not exposed on either tile. | P1 |

The unscored reflection may mention actual scale, materials, drainage, access, safety, rights or site survey, without asserting any fact about a real site.

**Proposed noncompensatory criteria (owner review, not an adopted threshold):** P1 requires correct R1 and either R3/R10 with explicit internal/external edge reasoning and *length* units. P2 requires R2 and R5 correct *square* units, plus the correct area comparison R1/R4. P3 requires all three R6 classifications and R7's direction-not-length explanation. P4 requires both R8 and R9 with four numerical comparisons, correct judgments and a counterexample. A high total must **not** compensate for a missing strand; recheck with an unseen form, not memorized R items. Responses can be oral/tactile/scribed with unchanged mathematical criteria. Human review must approve difficulty, correctness, equitable access, threshold, independent forms and delivery.
