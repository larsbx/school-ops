# Guided tasks G1–G7 — complete teacher key (draft)

[Guided learner page](guided-learner.md) contains no link to this key. All tile arrangements are connected and have no holes.

| Task | Exact answer with mathematical reason | Misconception/response |
| --- | --- | --- |
| **G1** | Six filled squares = **6 square units**. Exposed boundary 3+2+3+2 = **10 length units**. Internal joins are excluded. | Trace only external edges, not every side of six tiles. |
| **G2** | Six squares = **6 square units**. A 1×6 strip has exposed length 6+1+6+1 = **14 length units**. Area equals G1 but boundary differs because arrangement changes adjacency. | Do not equate “long-looking” with more tiles. |
| **G3** | A 1×4 strip has **area4 square units**, **perimeter10 length units**; G1 2×3 has **area6**, **perimeter10**. Equal perimeters but unequal areas are an explicit **counterexample** to “always.” | A bare “false” is not a sufficient logic/rhetoric demonstration. |
| **G4** | Five filled squares = **5 square units**. There are **5 internal shared full sides** (top row1, lower row2, vertical row connections2), so exposed perimeter 4×5−2×5 = **10 length units**. An outer walk top2, down1, right1, down1, left3, up2 also totals **10**. | Dot is empty; don't count any shared tile edge as exposed. |
| **G5** | Anticlockwise from east: northeast **less** than a right angle, north **equal** to right angle, northwest **greater** than right angle. These are directions, not endpoint distances. | Align shared vertices and initial rays before comparing. |
| **G6** | Choose 2×3 **among the offered two**: both areas **6 square units**, but its perimeter **10 length units** is smaller than 1×6 **14 length units**. The strip is longer on the page but covers the same six tiles. Does not prove global optimum among all shapes. | Demand constraint, two boundary counts and reason. |
| **G7** | **No angle change**: same common vertex and ray directions means identical opening despite lengths 2 versus 5; extend hinge arms *without rotating* them. | Ray length is not angle magnitude. |

**Independent arithmetic audit:** For N unit tiles with J full shared sides, exposed boundary = 4N−2J: G1 N6/J7→10; G2 N6/J5→14; G3 N4/J3→10; G4 N5/J5→10. This is a teacher consistency check, not an imposed pupil formula. Accept equivalent traced-edge explanations. Route failures to area counting, exposure tracing, angle hinge, or counterexample rehearsal individually.
