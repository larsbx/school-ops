**Source custody and conventions.** All shapes, model statements and keys below are original classroom constructions, not copied third-party readings. On a supplied equal-unit grid, `#` is one filled **unit square**; `.` is empty. Each tile side is one *length unit*. **Area** counts tiles (square units); **perimeter** counts *exposed unit-length sides* (length units). A shared full side is internal; touching at a corner does not hide a side. For angle tasks a common vertex and first ray pointing east fix the smaller **anticlockwise** comparison turn. Diagrams use supplied conceptual units, never actual site measurements.
