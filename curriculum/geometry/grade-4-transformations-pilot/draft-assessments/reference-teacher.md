# Grade 4 geometry — reference teacher key and proposed evidence criteria

**Draft; publicly exposed S1–S10 are practice/reference, not a secure or adopted assessment.** The allowed response is spoken, dictated, tactile or written on a labeled board, with the same content requirements. Untimed; require the stated operations rather than neatness/speed. Provisional scoring: each row 0 absent/incorrect; 1 correct answer without demanded checkable reason; 2 correct answer **and** the specified explanation. Do not convert totals to learner mastery. The proposed **noncompensatory** criteria are: P1 demonstrated on S1–S4/S7, P2 on S5/S6/S8/S10, P3 on S4/S7/S9, P4 on S8–S10, with an error-free essential construction *and* a reason in each category. **Owner must approve or revise** criteria and an independently fresh form before use.

| Task | Complete key, reason and scoring focus | Goal |
| --- | --- | --- |
| S1 | **(3,5)**; V maps column 2 to 3, leaving row 5 unchanged. | P1 |
| S2 | **(4,5)**; H maps row 0 to 5, leaving column 4 unchanged. | P1 |
| S3 | **{(5,0),(4,0)}**; the one-to-one map sends each of two distinct original cells to a distinct new cell, so both survive. | P1/P3 |
| S4 | **Yes**; B's columns **1↔4, 2↔3** in row 2, so its set is unchanged although individual cells exchange places. | P1/P3 |
| S5 | Q`(0,2)`=**(3,0)**; new column `5-r=5-2=3`, new row 0 is original column. | P2 |
| S6 | Q-images are **{(1,1),(1,2)}**, because `(1,4)→(1,1)` and `(2,4)→(1,2)`. | P2 |
| S7 | V(C)=**{(4,1),(4,2),(3,2)}**. Original C has **3 square units**, 2 shared sides, perimeter **12−4=8 length units**; mirror has the same area and two shared sides, thus **8 length units**. | P1/P3 |
| S8 | Right-shift gives **{(1,1),(1,2),(2,2)}**. V-image gives **{(5,1),(5,2),(4,2)}**. The sets differ, so **false**; an ordinary translation is not the specified central reflection. | P2/P4 |
| S9 | **False**: both have **4 square units** of area. A has 3 shared sides, **16−6=10 length units**; D has 4 shared sides, **16−8=8 length units**. These unequal perimeters refute the **invalid generalization** that equal area determines perimeter. Conservation concerns a shape and its rigidly moved copy, so this comparison does not challenge it. Full evidence includes both measurements with units, the shared-side reason and this distinction. | P3/P4 |
| S10 | First V`(1,1)`=**(4,1)**, then Q`(4,1)`=**(4,4)**. Each preserves single-cell area and lengths/adjacency of a shape. Reverse order Q`(1,1)`=**(4,1)** then V`(4,1)`=**(1,1)**, **not equal**. Operations do not commute for this point. | P2/P4 |

Use the [teacher-only logic check](../guided-teacher.md#teacher-only-logic-check) to distinguish conservation from its actual converse and from the invalid generalization. S9 assesses the equal-area claim and its relation to conservation; no converse terminology or A/E example is required for credit.

## Teacher decision matrix (proposal only)

- If P1 construction is absent, reteach row/column pairs using a new non-card figure; independently recheck a fresh V/H image.
- If P2 is absent, use a tactile labeled board to distinguish clockwise movement from left/right flip; recheck a new point under Q.
- If P3 is absent, trace exposed edges before and after a transformation of a *new shape*; do not replace boundary with cell count.
- If P4 is absent, revisit "equal area always means equal perimeter" with two new shapes having **equal area and different perimeters**. Ask for both measurements and a counterexample/revised claim. Noncongruence alone does not ensure different perimeters; check the measurements before choosing the pair.

**Review blockers:** independently confirm keys, coordinate definitions and scoring fairness, assess age/access/scribe equivalence, approve an unseen form and thresholds, establish agreed time and source/material availability. No canonical assessment ID, readiness or private learner record is authorized by this packet.
