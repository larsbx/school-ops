# Four Trivium-rich instructional episodes — illustrative, not scheduled

**Draft/not ready:** four proposed 25-minute episodes, not lessons with stable IDs or an agreed timetable. Read the [coordinate packet](coordinate-cards.md), [entry results](entry-learner.md) and [keys](entry-teacher.md) first. A learner who cannot distinguish row/column or shared/corner sides needs targeted instruction before formal transformations. Teacher models are coached, never hidden assessment. Separate [X1–X4 keys](guided-teacher.md).

## Episode 1 — What does a mirror preserve?

**Primary art:** geometry (whole unit squares on an equal-cell board); arithmetic for counting unchanged cells.

| Trivium move and actual teaching work | Minutes |
| --- | --- |
| Grammar: name column, row, V axis, corresponding square; learners read A's four coordinates aloud or by touch | 5 |
| Logic: place a token at `(0,1)`, reflect to `(5,1)`; test false proposal `(0,1)→(0,5)` and explain that it changes the row, not the column | 7 |
| Construct: teams map all Card A cells across V, crossing off each source exactly once; compare sets and count | 6 |
| Rhetoric: each learner defends one pair with "same row, mirror-distance column" and checks another's explanation | 5 |
| **X1.** Independently reflect `(0,3)` under V and give a reason involving the axis | 2 |

## Episode 2 — When does a pattern reflect to itself?

**Primary art:** geometry; use Card B. A symmetric whole pattern may exchange *individual* cells and still equal the original set.

| Trivium move and actual teaching work | Minutes |
| --- | --- |
| Grammar: distinguish fixed *set* from fixed *individual cell*; read B's row-2 coordinates | 5 |
| Logic: reflect all four B cells across V; compare sets, not the list order; test "every cell stayed where it was" | 7 |
| Inquiry: reflect a single tile twice and investigate which number changes the second time | 6 |
| Rhetoric: explain how the image can equal B even while columns exchange positions; peer challenges with `(1,2)` | 5 |
| **X2.** Reflect `(2,2)` under V twice; list both images and decide whether B as a whole is V-symmetric | 2 |

## Episode 3 — A turn is not a mirror

**Primary art:** geometry of quarter-turns, with coordinate arithmetic `5-r`. Row numbers increase downward.

| Trivium move and actual teaching work | Minutes |
| --- | --- |
| Grammar: explain clockwise, center and fixed board labels; orient a raised or printed board | 5 |
| Logic: test Q on `(1,4)` and contrast V on the same cell; debate why using `(r,c)` is not the stated rule | 7 |
| Build: rotate Card A using the explicit Q rule, then show that the four original cell labels are not physically moved | 6 |
| Rhetoric: provide a two-cell explanatory trace that another learner can reproduce, including coordinate order | 5 |
| **X3.** Calculate Q`(2,4)` and V`(2,4)`; explain why the outputs differ | 2 |

## Episode 4 — Conservation is not its converse

**Primary art:** geometry and arithmetic of unit-square area and exposed-side perimeter.

| Trivium move and actual teaching work | Minutes |
| --- | --- |
| Grammar: distinguish area in square units and boundary in length units; define a counterexample | 5 |
| Logic: independently count Card A and D, note equal areas but compare perimeters; locate shared sides | 7 |
| Investigation: use the matching rules to argue a rigid V or Q move preserves side adjacency and hence perimeter; challenge "same area always means same perimeter" | 6 |
| Rhetoric: write or dictate a two-part museum label: one valid conservation claim, one bounded false-converse counterexample | 5 |
| **X4.** Compare the perimeter of Card D and Card E, which each have four unit squares; explain whether equal area forces equal boundary | 2 |

**Diagnostic routing:** If X1 fails, revisit E2/E4 and map columns with new points. If X2 fails, distinguish a symmetric set from unmoved cells, then test another bar. If X3 fails, use `Q(c,r)=(5-r,c)` with a new point and independent recheck. If X4 fails, trace and count exposed sides (E3) with a new arrangement. Do not claim mastery from this sequence, and retain all accommodations.
