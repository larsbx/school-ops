## Exact domain and learner materials

Read the [original coordinate-card packet](coordinate-cards.md) before using [entry tasks](entry-learner.md), [four episodes](lessons.md), [guided tasks](guided-learner.md) or the [exposed reference tasks](draft-assessments/reference-learner.md). Teacher-only review surfaces: [entry key and distinct rechecks](entry-teacher.md), [guided and exit keys](guided-teacher.md), [reference key/rubric](draft-assessments/reference-teacher.md).

Each cell is a **unit square**, identified by integer `(column,row)` on the original 6×6 board (columns and rows 0–5; rows increase downward). A vertical mirror runs **between** columns 2 and 3: `V(c,r)=(5-c,r)`. The horizontal mirror runs **between** rows 2 and 3: `H(c,r)=(c,5-r)`. A clockwise quarter-turn about the board's center sends `Q(c,r)=(5-r,c)`. These are moves of whole cells, **not** geometric claims about a square cut through a cell. Area counts filled squares; perimeter counts exposed unit-length cell sides, including any holes. All transformed shapes stay on the board and retain the same-sized cells. Terms `mirror`, `turn`, `axis`, `corresponding cell`, `area`, `perimeter`, and `counterexample` must be used meaningfully.

## Proposed sequence and supports

1. [Episode 1](lessons.md): name and construct a vertical reflection; show exactly which square corresponds.
2. [Episode 2](lessons.md): test a claimed line of symmetry and inverse mirrors.
3. [Episode 3](lessons.md): construct a quarter-turn with `(c,r)` conventions; rebut mirror/rotation confusion.
4. [Episode 4 — Same area, different perimeters](lessons.md): justify that rigid grid transformations preserve both area and perimeter, then use Cards A and D to refute the invalid generalization "same area implies same perimeter."

The [teacher-only logic check](guided-teacher.md#teacher-only-logic-check) distinguishes conservation, its actual converse, and the invalid generalization tested here. Learner work asks for a conservation reason and an equal-area counterexample; the separate converse explanation adds no learner task or assessment criterion.
