# Learner booklet — reading agreements carefully

All clubs, people and records below are **invented classroom examples**, not Islamic history, scripture, hadith or religious rulings. A separate religious reading may be provided only after teacher review. Read, listen, point, dictate, write or use AAC. Blank frame: “Record ___ says ___; therefore ___; we do not know ___.” No personal faith or family information is requested.

## Entry and recheck

**E1.** A librarian's slip records a door open. A pupil says the librarian wanted a party. Which is recorded and which inferred?

**E2.** Draft: bring two boxes. Accepted note: bring one box. Which sets the agreed number? Name it.

**E3.** A cart may enter if its wheels are clean. A has clean wheels; B was not checked. Which meets the condition? What do we know about B?

**E4.** Notice: return ruler by noon. Pupil suggests dusk. Explain which to use and why, naming the notice.

**R1.** Hall slip records window shut. Someone says caretaker was angry. Separate record and inference.

**R2.** Draft: three bags. Accepted note: two bags. Which sets the agreed number?

**R3.** A tray may be placed on a shelf if dry. C is dry; D not checked. Which meets the condition and what remains unknown?

**R4.** Notice says collect cards at desk; pupil suggests outside. Explain which to use and why, naming the record.

## Fictional packet

The Cedar and Willow clubs share a reading room.

| Card | Kind | Record |
| --- | --- | --- |
| A | Proposal, Monday | Cedar suggests keeping the blue cupboard until Friday. |
| B | Accepted agreement, Tuesday | Both clubs agree Cedar may use the cupboard until Thursday. Willow may use it Friday if the key has returned to the desk. |
| C | Desk log, Friday | The key was returned before opening. Willow collected it. |
| D | Later recollection | A helper saw Willow collect the key; the helper did not see the return. |
| F | Opinion | A pupil says Cedar changed the wording because it disliked Willow. |

| Case | Key returned before Friday opening | Friday use supported by B |
| --- | --- | --- |
| K1 | yes | ? |
| K2 | no | ? |
| K3 | unknown | ? |

## Guided work

**G1.** Compare A and B: name the different final days and identify which wording controls.

**G2.** Correct the claim that Cedar may use the cupboard Friday under the accepted agreement. Cite a card.

**G3.** Decide K1 and K2 under B. Explain the condition.

**G4.** For K3, is permission established? What would settle it?

**G5.** Which part of C is also reported by D? Which part is not independently reported by D?

**G6.** Does C or D establish Cedar's reason for changing the wording? Classify F.

**G7.** Rewrite “Cedar disliked Willow, so Willow took the key” using B and C and a limitation.

**G8.** A pupil calls A a hadith. Correct this and name source information and qualified review a real report would need.

## Independent exits

**X1.** A fictional draft says use hall until 4; accepted note says until 3. Correct the claim “4 is agreed.”

**X2.** An agreement allows art club to borrow brushes if box labeled. J is labeled; K is not. Which is permitted and why?

**X3.** Desk log records bag collected; witness recalls collection but not contents. Does the witness confirm the contents? Why?

**X4.** Accepted notice N permits pickup after adult signs. Log M records signing and pickup. Pupil claims adult was happy. Revise using N and M and one uncertainty.

## Exposed reference — new fictional packet

Pine and Oak clubs share a model display.

| Card | Kind | Record |
| --- | --- | --- |
| H | Proposal | Pine suggests leaving models on table through Wednesday. |
| J | Accepted agreement | Both agree Pine clears table Tuesday. Oak may display Wednesday if table is cleared. |
| K | Caretaker log | Wednesday morning table was clear; Oak displayed models. |
| L | Later witness report | Witness saw Oak displaying; did not see Pine clear table. |
| M | Opinion | A pupil thinks Pine cleared table because it feared a complaint. |

**S1.** Identify H and J by kind. On which day must Pine clear the table? Cite the card.

**S2.** Correct “Pine could leave models until Wednesday.” Name the controlling card and explain change.

**S3.** In another week table is clear Wednesday; in a different week it is not. Apply J to both and name condition.

**S4.** Third week has no table report. Is permission established? What needs checking?

**S5.** What action do K and L both report? What detail does L not confirm?

**S6.** Does K or L establish why Pine cleared the table? Classify M and name gap.

**S7.** Revise “Pine feared a complaint and Oak displayed without permission.” Cite J and K; reason and uncertainty required.

**S8.** A pupil labels J a historical treaty and claims it decides a religious ruling. Correct both claims. Name one source metadata field and one qualified review needed before using a real religious report.
