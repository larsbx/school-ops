# Lesson 1 — A source reference is not the source text

- **Status/kind:** draft Grade 3 Islamic studies lesson, ID unassigned; **not ready**
- Local target: [G3-IS-P1](../README.md#local-outcome-to-evidence-contract)
- **Prerequisite:** E1 [source-label check](../draft-assessments/entry-check.md#e1--source-label-prerequisite), E4 communication access
- Proposed duration: **25 minutes**, pending agreed timetable
- Materials: [original Cards A–E](../learner-cards.md), paper, pencil / accessible response mode
- Primary study: source custody in Islamic studies. Music excluded; no claim to teach a mathematical art.

## Trivium work and observable goal

- **Grammar:** correctly use `sūrah`, `āyah`, `hadith report`, `translation metadata` and `teacher note`.
- **Logic:** explain why a locator identifies *where to verify* but not the words themselves; cite a missing field to reject unsupported conclusions.
- **Rhetoric:** teach someone how to find A or D without claiming Card B provides an approved translation.
- **Criterion:** independent classification of five record types **at least 4/5**, plus correctly identifying **both** references, Qur'an 49:13 and Sahih al-Bukhari report 8. Model source and [rubric](../draft-assessments/unit-check-teacher.md#outcome-specific-criteria-and-remediation).

## Teacher key and feedback

**A:** Qur'an locator 49:13; **B:** unfilled translation metadata, no words; **C:** original teacher explanation; **D:** hadith report locator Sahih al-Bukhari 8, not chain verification; **E:** invented scenario. A mistaken sacred attribution for C/E requires correction even if a 4/5 count is met.

If E1 or P1 evidence is missing, show two new *neutral* labels, compare locator/text/paraphrase, then independently reassess. Enter Lesson 2 only after E3 is also addressed. No learner evidence has been observed; scholarly and teaching reviews remain open.
