# Lesson 2 — What a claim establishes and what remains unknown

- **Status/kind:** draft Grade 3 Islamic studies lesson, ID unassigned; **not ready**
- Local target: [G3-IS-P2](../README.md#local-outcome-to-evidence-contract)
- **Prerequisites:** E3 [neutral fact/inference check](../draft-assessments/entry-check.md#e3--observation-versus-inference); revisit P1 classification as needed; E4 access
- Proposed duration: **25 minutes**, not school-approved
- Materials: [T1–T4 and Card B/D](../learner-cards.md#separate-four-claim-cards), blank claim/reason sheet

## Trivium and goal

- **Grammar:** distinguish `quotation of fictional text`, `teacher explanation`, `student inference`, `unsupported assertion`; never treat these as Qur'anic words.
- **Logic:** challenge T4 by checking precisely what Card D does **and does not** contain, and state why Card B cannot supply a translator's words.
- **Rhetoric:** explain "the record says / I infer / what I cannot know" with one explicitly labeled limitation.
- **Proposed criterion:** independently classify **3/4** claim types, explicitly reject **T4** as unsupported, and state that **Card B has no actual translator or wording**, per [teacher rubric](../draft-assessments/unit-check-teacher.md#outcome-specific-criteria-and-remediation).

## Actual sequence

| Phase | Prompt and work | Minutes |
| --- | --- | ---: |
| Entry | "What is the difference between copied diary words and a statement about a diary?" Show neutral example. | 3 |
| Worked comparison | Read T1 and T2. "Who actually wrote the sentence? Does it become sacred because it is in quotation marks?" | 6 |
| Guided reasoning | Compare T3 and T4. "Can Card D confirm a Hijrah route/date or authenticate all narrators? Where is the evidence?" | 7 |
| Independent | With teacher labels covered, classify **T1–T4** and answer: "What exact English translation can Card B supply?" | 6 |
| Exit | "Name one verifiable thing from D, one unverifiable thing from D, and why that matters." | 3 |
| **Total** | | **25** |

## Teacher key and response

T1 = direct quotation of a **fictional diary**; T2 = teacher's explanation; T3 = qualified student inference; T4 = unsupported Hijrah/authenticity claim. D is a locator only, and B has no translator/edition/text. See the [complete assessment key](../draft-assessments/unit-check-teacher.md#complete-model-answers).

Correct a false religious quotation or authentication claim immediately, even if 3/4 labels are right. If unsuccessful, test independent new neutral examples before rechecking. Do not assess worship or presume any private faith/parental practice.
