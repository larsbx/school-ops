# Grade 3 Islamic studies — source-literacy teaching pilot

- **Kind:** unregistered, **draft/not ready** course/unit authoring prototype, **not** a classroom-approved course.
- **Audience:** intended Grade 3 learners; prerequisites, language, accessibility and materials require actual checks.
- **Formal IDs:** **unassigned**. `G3-IS-P1` and `G3-IS-P2` are **local planning labels only**, adopted from the [Grade 3 scaffold](../../scaffolds/grade-3/islamic-studies.md).
- **Provisional time:** two 25-minute lessons and a 15–20-minute unit check, not an agreed timetable.
- **Subject:** Islamic studies, using grammar, logic and rhetoric; neither a Quadrivium art nor a substitute for Grade 2 mathematics.
- **Scholarly/source/translation review:** **pending**, as is school scope adoption.

## Distinct advancement

The existing [Grade 2 Islamic studies prototype](../grade-2-prototype/README.md) introduces basic Qur'an/hadith source labels, the five pillars and character. This Grade 3 pilot does **not** repeat the five-pillar check. It instead investigates **source metadata versus text**, translator and edition availability, teacher commentary, original fictional records and unjustified religious/historical claims. No prior mastery is assumed. This is **only** the first two of [six Grade 3 planning episodes](../../scaffolds/grade-3/islamic-studies.md); sīrah chronology, map claims and wuḍūʾ/ṣalāh terminology are not authored here.

## Local outcome-to-evidence contract

| Local label | Observable goal | Independent task and criterion |
| --- | --- | --- |
| G3-IS-P1 | Distinguish five labeled record types: Qur'an locator, translation **metadata**, teacher explanation, hadith report locator and fictional narrative; identify actual lookup metadata. | [Learner check](draft-assessments/unit-check-learner.md) Tasks 1–2: **4/5 correctly classified and both locators** (Qur'an 49:13 and Sahih al-Bukhari 8). |
| G3-IS-P2 | Recognize quotation of *fictional* text, teacher comment, qualified learner inference and unsupported historical/authenticity claim; preserve unknowns. | Learner check Tasks 3–4: **3/4 classifications**, explicit rejection of unsupported T4, and acknowledgment that Card B provides **no translator's actual wording**. |

These are **proposed criteria**, not observed results. Correcting misattribution is required even where a numeric threshold is reached. No personal faith or worship may be assessed.
