# Grade 3 Islamic studies — draft independent unit check (learner)

- **Status:** draft/unregistered/not ready; no formal assessment ID.
- **Targets:** G3-IS-P1 and G3-IS-P2 local planning outcomes.
- **Proposed conditions:** 15–20 minutes; individual; [A–E and T1–T4 learner cards](../learner-cards.md) available; read-aloud, oral/drawn/AAC answers and extra time where needed. **Do not present teacher key, answer labels, or worked matching strips**.
- Cards contain no translated scripture or actual hadith text. No personal faith or ritual questions.

## Actual learner tasks

**Task 1 (P1):** For each Card **A, B, C, D, E**, choose exactly one: *Qur'anic text locator*, *translation metadata without wording*, *teacher-created explanation*, *hadith collection/report locator*, *invented classroom note*. Give a reason for at least one choice referring to the card.

**Task 2 (P1):** Tell a friend how to locate the named passage in A (give sūrah and āyah), and the named report in D (give collection and number). Which card has a place for a translator but **no chosen translator or actual English translation**?

**Task 3 (P2):** For each statement **T1, T2, T3, T4**, choose: *quotation from a fictional diary*, *teacher's explanation*, *qualified student inference*, or *unsupported historical/authenticity claim*. Give a reason why one is supported or unsupported.

**Task 4 (P2):** Complete the three-part explanation: "From Card D's locator I can establish ___; from this locator I **cannot** establish ___; Card B cannot supply a quoted English translation because ___."

**Task 5 (formative communication, P1/P2):** Explain one classification to a peer using "the label says / I infer / I cannot yet know". Task 5 informs feedback but cannot replace missing evidence in Tasks 1–4.

These are **authored exemplar tasks**, not automatically re-generated forms. Fresh practice sessions can use the [draft generator and its saved-session contract](../practice-variation.md); this review exemplar itself remains unchanged. Responses are private; only generic teacher model evidence is in Git.
