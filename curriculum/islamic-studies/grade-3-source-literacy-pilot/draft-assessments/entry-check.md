# Grade 3 Islamic studies — independent entry diagnostic

- **Record kind:** unregistered draft diagnostic, **not ready** for classroom deployment.
- **Audience:** intended Grade 3; no assumed Arabic fluency, ritual participation, or prior Grade 2 attainment.
- **Conditions:** proposed 8–10 minutes, individual responses, read-aloud / drawing / AAC supported. Use these original *neutral* classroom materials; do not quote scripture.

## E1 — source-label prerequisite

Provide **four separate** cards, not a matching strip. Ask: "For each, is this (a) a source *locator* with no copied words, (b) a *direct quotation* of an invented note, (c) the teacher's *paraphrase* of an invented note, or (d) a *fictional scenario*? Show one feature that helps you tell."

| Card | Original learner-visible record |
| --- | --- |
| N1 | `File name: Classroom journal; page: 7; journal words: not attached.` |
| N2 | `Exact words in an imaginary classroom diary: "I saw two birds."` |
| N3 | `Teacher's shortened description of an invented class report: "It was windy."` |
| N4 | `Imagined situation: A pupil borrowed a ruler to draw a line.` |

**Teacher key (not learner-facing):** N1 locator, N2 quotation **only of fictional text**, N3 teacher summary, N4 imaginary scenario. **Candidate threshold:** 3/4 correct classifications and no invented card falsely called scripture. If missing, model source/text/summary distinctions and retest on different neutral records. The answer categories printed in the prompt are permitted, but do not verbally tell the learner which card matches.

## E3 — observation versus inference

1. `Record: There are three pencils on the desk.` `Claim: Therefore, the pencils belong to the teacher.` Ask which is recorded and which is inferred. **Key:** first is reported observation; ownership is not established.
2. `Record: The story mentions a door.` `Claim: Therefore, the door must be red.` Ask the same. **Key:** the story only mentions a door; the color conclusion is unsupported.

**Candidate threshold:** 2/2 distinctions. If missing, model "record says / I infer" with another neutral pair before Lesson 2.

## E4 — response-mode access

Ask the learner to identify or describe an ordinary room object using speech, pointing, writing, drawing or assistive communication. Arrange effective access. **Do not count disability, English or Arabic-language need as a religious-content failure.**

## Progression gate

Check E1 before Lesson 1, E3 before Lesson 2, and E4 for all encounters. There is no combined pass/fail score, no assumed prior mastery and no learner records in Git. The religious and age-appropriate review remains pending.
