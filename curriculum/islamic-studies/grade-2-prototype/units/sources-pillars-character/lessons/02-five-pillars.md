## Observable goal

**IS2-P02:** At least 4/5 correct matches on the individual check, and cite Card H as a report from Sahih al-Bukhari 8. See [unit check](../../../draft-assessments/unit-check.md) for the independent end-of-unit criterion.

## Trivium work

- **Grammar:** use Qur'an, surah/ayah, hadith/report, or ethical terms from the card with correct meaning and attribution.
- **Logic:** identify what evidence the named card actually provides; distinguish inference from source wording and test one incorrect claim.
- **Rhetoric:** give an ordered explanation aloud, in writing or with a labeled diagram and oral narration.

## Independent exit prompts

Present only the following task and Card H's **source label**. Cover the worked matching strip, Card H summary and teacher keys during this check. Each learner supplies all five matches individually; the teacher may read every term, choice and question aloud without indicating a pairing. Keep large-print, oral, pointing or drawn responses and teacher transcription available; record each selected letter separately. No partner answers or content hints count as independent evidence.

Match each term to one description, using each letter once:

| Prompt | Term |
| --- | --- |
| M1 | shahādah |
| M2 | ṣalāh |
| M3 | zakāh |
| M4 | ṣawm of Ramadan |
| M5 | ḥajj |

| Choice | Beginner description |
| --- | --- |
| A | pilgrimage to Makkah |
| B | testimony of faith |
| C | obligatory charitable giving |
| D | fasting in Ramadan |
| E | prescribed prayer |

**Source question:** Name Card H's collection and report number. Are these descriptions the teacher's summary or an exact hadith quotation?

Allow the proposed six minutes, with additional access time as needed; speed is not assessed. If a learner has not supplied all five responses, record **insufficient evidence**, then arrange a fresh complete individual check. Do not fill gaps using supported practice.

## Teacher key, feedback and progression

**Evidence threshold:** At least 4/5 correct matches on the individual check, and cite Card H as a report from Sahih al-Bukhari 8.

**Exit key (teacher only):** M1 → B; M2 → E; M3 → C; M4 → D; M5 → A. Source: *Sahih al-Bukhari*, report 8; the descriptions are a teacher summary, not a quotation. Inspect all five responses, score one per correct pair, and require **at least 4/5 plus the source identification**. Do not average away missing source evidence; retain only private records of responses and permitted support.

**Expected reasoning:** Refer to the [card-specific model answers](../teacher-pack.md). Accept faithful oral/drawn explanations, not unsupported text copying or unreviewed authenticity assertions.

**Next action if absent:** If a term is mixed up, use an example/nonexample and retry a fresh match. No pupil is required to perform any act of worship.

The next lesson is a proposed progression, not confirmation of demonstrated mastery. Individual learner evidence stays private. Source wording, accessibility and qualified review still block teaching readiness.
