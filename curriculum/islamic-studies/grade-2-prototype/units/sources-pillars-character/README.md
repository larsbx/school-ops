# Prototype unit — Sources, pillars and character

- Status: **draft; no formal unit ID**
- Parent: [Grade 2 Islamic studies prototype](../../README.md)
- Planned authoring duration: 4 × 25 minutes, plus 20-minute check (not agreed)
- Entry evidence: [entry check](../../draft-assessments/entry-check.md); reading aloud and oral/drawn responses supported
- Material: [teacher-authored source cards](teacher-pack.md), access to reviewed primary references when approved, pencils, paper
- Outcomes: IS2-P01 to IS2-P04 (local labels; see [course outcomes](../../README.md#prototype-outcomes))
- Primary study: Qur'an/hadith provenance, Islamic pillars and ethical language
- Trivium: naming and attribution, reasons from evidence, clear oral/written explanation

## Ordered lessons

| Lesson | Purpose | Evidence targeted | Minutes |
| --- | --- | --- | ---: |
| [01 — Source labels](lessons/01-source-labels.md) | Qur'an, report, original scenario | IS2-P01 | 25 |
| [02 — Five pillars](lessons/02-five-pillars.md) | Names and descriptions from a cited report | IS2-P02; revisit P01 | 25 |
| [03 — Named Qur'anic passage](lessons/03-quran-and-people.md) | Theme and distinction between source text and teacher summary | IS2-P03; revisit P01 | 25 |
| [04 — Claim and reasons](lessons/04-reasoning-from-sources.md) | Source attribution and ethical application | IS2-P04; revisit P01/P03 | 25 |

## End-of-unit evidence and decision

Administer [unit check](../../draft-assessments/unit-check.md), separate from practice and requiring source recognition and individual reasoning. Apply **outcome-specific** criteria; an overall points tally cannot substitute for the specific criteria. If an outcome is missing, reteach the relevant card/claim and use a new comparable item before progression. This unit and the evidence plan are drafts; no student has been assessed.

## Review blockers

Source and translation approval, qualified review, scope/time agreement, local access and assessment acceptability. No readiness promotion or individual learner data.
