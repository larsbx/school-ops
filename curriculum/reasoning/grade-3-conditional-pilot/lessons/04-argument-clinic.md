# Lesson 4 — Repair an argument and respect its boundary (teacher-facing draft)

**Status: draft/not ready.** Provisional **25 minutes**; local goals `G3R-P1`–`G3R-P3`. Entry: guided P1–P8 reviewed, but no automatic inference that the learner mastered them. Use only the [invented packet](../rule-cards.md), not private class information.

## Trivium and the actual investigation

- **Grammar:** accurately distinguish `premise`, `conclusion`, `converse`, `counterexample` and `unknown`.
- **Logic:** critique “B is dotted; therefore B has a number.” The conclusion is unsupported by the dot property, **and B's Number entry is no**. Contrast this with the warranted R2/R3 triangle chain.
- **Rhetoric:** present a concise checkable correction and tell a peer where the evidence stops: facts about a hypothetical future card are **unknown** from the six-card table.

## Proposed 25-minute teaching sequence

| Phase | Minutes | Usable teacher and learner actions |
| --- | ---: | --- |
| Retrieval and comparison | 4 | Learners recall one true forward rule and one false converse, citing a row. |
| Critique a proposed proof | 6 | Read “Card B is dotted. All dotted cards have numbers. Therefore B has a number.” Ask which premise was invented; check B's Number cell. |
| Guided boundary inquiry | 6 | Solve P8. Draw a box around A–F; a future G is outside it. Contrast “false inside pack” with “not established outside pack.” |
| Present and revise | 6 | Learners present a corrected argument linking R2 and R3 and critique an unjustified extrapolation. Peers request field/rule evidence. |
| Independent exit X4 | 3 | Ask: “A seventh card **G** is not in the packet. A classmate says G must be numbered because R3 was true in A–F. What should you conclude and what would make an answer possible?” |

**Teacher exit key X4:** **Unknown** for G. The table/rules explicitly describe **only A–F**. Need the G row's Number field, or an explicitly applicable rule and enough premises for G; R3 **on A–F** cannot be extended without authorization. This is not a claim that G has no number.

**Feedback:** If an outside-packet assertion is called false automatically, distinguish **false** (a known counterexample) from **unknown** (no supplied evidence). If an argument is correct by chance but lacks a valid premise, ask which exact arrow justifies the result.
