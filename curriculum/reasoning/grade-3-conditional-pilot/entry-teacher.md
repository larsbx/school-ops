# Entry check — teacher key and gating (draft, not ready)

Use [learner-only E1–E4](entry-learner.md) and the [six-card ledger](rule-cards.md). Do not expose this key during the diagnostic. These are *proposed* entry checks and criteria, not observed results. Record any actual learner evidence privately.

| Item | Model response | Proposed decision and remediation |
| --- | --- | --- |
| **E1** | A has **dot: yes**, as shown in A's Dot column. | Needs accurate field reading to begin Lesson 1; if wrong, model navigating one **different** column on card C and recheck with B. |
| **E2** | **B** or **D**, each has **square** and **dot: yes**. | Needs both facts. If missing, point to Form and Dot columns on a **different** row; recheck with the other valid row. |
| **E3** | **No**; **E** is a **square** with **dot: no**, so “every square” is false. | Must reject the universal claim **and** name E with both fields before Lesson 2. If not, compare B and E (both squares, different dot entries), then use a different universal rule as a new check. |
| **E4** | Explains chosen card via two referenced cells; valid oral, typed, drawn or AAC reasoning. | Identify an accessible response mode. Do **not** treat disability, color perception, written fluency or response speed as a lack of reasoning. |

### Recheck without rehearsing the answer

After coaching on counterexamples, ask whether “**every card with a dot is blue**” is true for this packet; a successful independent response says **no**, cites **D: red, dot yes**. This is **not E3's original prompt**, although it uses the same packet. A failed E3 requires another instructional cycle; do not overwrite the first result.

After E1/E2 remediation, ask for the **form and stripe** values of C (triangle, yes) and a **blue dotted** card (A or B). E4 is not a speed or handwriting test. No aggregate score substitutes for each component.
