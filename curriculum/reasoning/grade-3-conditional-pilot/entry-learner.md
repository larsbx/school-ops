# Entry check E1–E4 — learner sheet (draft, not ready)

Use the complete [six-card ledger](rule-cards.md). You may point, speak, draw, dictate, use text, or use AAC. There is no fixed time limit. The teacher may read the table and questions aloud but may not reveal which answer to select.

**E1 — Read a row.** Look at card A. Does A have a **dot**? State the value you used from the table.

**E2 — Find an example.** Name **one square with a dot**. State both its form and dot entries.

**E3 — Test an all-claim.** A student says, “**Every square has a dot** in this packet.” Is the student correct? Name a card and the relevant fields that settle the claim.

**E4 — Explain an example.** Show or tell another learner how the card you chose for E2 supports your answer. Explain how you would prefer to communicate the same reasoning.

This diagnostic is for choosing teaching supports, **not** a final score or a readiness claim. See teacher material only when checking responses.
