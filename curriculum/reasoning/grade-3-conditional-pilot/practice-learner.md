# Guided practice P1–P8 — learner sheet (public draft)

Use [the full six-card packet](rule-cards.md) throughout. All questions concern **only this packet**, except P8, which deliberately asks about a different domain. Responses may be spoken, drawn, written, or conveyed by AAC.

**P1.** List every **blue** card. How do you know the list is complete?

**P2.** List all cards that have a **dot**.

**P3.** Is “if dotted, then blue” true for this packet? If not, name one card that shows why.

**P4.** Check “if triangle, then striped”: name **every** triangle and the Stripe field for each.

**P5.** Is “if numbered, then striped” true for this packet? Give a counterexample if false.

**P6.** Complete a chain: “triangle → ______ → number”. Which two written rules license it?

**P7.** Someone says “dot → number.” Which **card** shows that this is not licensed, and which two fields matter?

**P8.** A new seventh card will arrive tomorrow. Can these six rows alone tell us whether it is blue? State what further evidence would be needed.

These are **practice** questions with a public key; they are not an unseen assessment or a claim of mastered outcomes.
