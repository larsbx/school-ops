# Original fictional card packet (learner-visible; draft)

This is **an invented, complete packet of exactly six cards**. All columns describe only these six named cards. No conclusions follow about unseen or future cards. Read each word, not only a color or shape glyph. A teacher can print a labeled/high-contrast table, provide tactile tags, or read a row aloud without changing its logical facts.

| Card | Color label | Form label | Dot | Stripe | Number |
| --- | --- | --- | --- | --- | --- |
| **A** | blue | triangle | yes | yes | yes |
| **B** | blue | square | yes | no | no |
| **C** | red | triangle | no | yes | yes |
| **D** | red | square | yes | no | no |
| **E** | green | square | no | no | yes |
| **F** | green | triangle | no | yes | yes |

**Rule R1:** If a card is **blue**, it has a **dot**.

**Rule R2:** If a card is a **triangle**, it has a **stripe**.

**Rule R3:** If a card has a **stripe**, it has a **number**.

Each rule is true *for this complete packet* as the table demonstrates. The word **if** tells the direction from the stated condition to what follows; it does not automatically say **only if**, and the converse must be checked.

**Vocabulary:** A **witness** is one card that meets a claim; a **counterexample** is one card that makes a proposed universal claim false; a **converse** reverses an if–then rule. **Unknown** means the packet provides no evidence for the different domain being asked about. These are teacher-selected working definitions, not an assertion that Grade 3 mastery is present.

**Source and rights:** card properties, labels and claims were newly authored for this pilot. No historical record, proprietary image, external quotation, scripture, hadith, Arabic translation or student data is represented.
