# Grade 3 reasoning — rules, converses and chains (draft teaching pilot)

**Status: draft / not ready.** This is an **unregistered authoring prototype**, not an adopted course, unit, timetable, or evidence of learning. Course, unit, lesson, assessment and formal outcome IDs remain **unassigned**. The labels `G3R-P1`–`G3R-P3` below are **local planning labels**, not canonical records. Provisional lesson durations are **not** an approved calendar.

**Audience:** learners provisionally considered for Grade 3, with actual prerequisites checked rather than presumed from age. **Subject:** logic/dialectic and the full Trivium (grammar, logic, rhetoric). Cards use visual form and counts as familiar representations, **not** a new geometry or arithmetic attainment claim. Music excluded.

**Prior work and nonduplication:** follows [Grade 3 reasoning scaffold](../../scaffolds/grade-3/reasoning.md); it does not reproduce [Grade 2 mathematics](../../mathematics/grade-2/README.md), the [Grade 2 Islamic studies prototype](../../islamic-studies/grade-2-prototype/README.md), or [Grade 3 Islamic source-literacy work](../../islamic-studies/grade-3-source-literacy-pilot/README.md). It builds **neutral, completely invented card premises**, so no source quotation, fiqh position, hadith authenticity or religious interpretation is involved. All K–12 Islamic studies planning and qualified review gates remain in force separately.

## Intended scope and boundary

A claim about **all six cards in one supplied closed packet** can be checked by exhaustively inspecting the [original classroom card ledger](rule-cards.md). Treat `if A then B` as the one-way rule from condition A to consequence B; do not assume the converse. Use a counterexample to reject an overbroad rule. Chain two warranted implications without adding an unsupported one, and keep the **packet boundary** explicit. Never generalize the invented rules to actual physical objects, unseen cards, personal traits or future packs.

| Local planning label | Proposed observable objective | Independent reference evidence (draft) |
| --- | --- | --- |
| `G3R-P1` | Read all fields and verify or falsify a quantified claim **within the given six-card pack**, naming a specific witness or counterexample. | [Reference Q1–Q3](draft-assessments/reference-learner.md); require Q1 all cards, Q2 a counterexample, and Q3 an accurate packet claim. |
| `G3R-P2` | Translate a one-way rule accurately and distinguish it from its converse, testing the converse rather than guessing. | Reference Q4, Q5, Q7; each interpreted correctly, with **Q7's counterexample E** required. |
| `G3R-P3` | Explain a valid two-link rule chain; identify an invalid inference and state when evidence does not license an outside-packet claim. | Reference Q6, Q8, Q9; all three components, including the scope limitation, required. |

Thresholds above are **proposed authoring criteria**; they are not assessments administered, readiness observations or evidence of learner mastery. No averaged pass overrides a missing component.

## Prerequisite entry and remediation

Use the [learner entry sheet](entry-learner.md) with [separate teacher solutions](entry-teacher.md). `E1` table decoding and `E2` example selection gate Lesson 1; `E3` explicit counterexample/reason gates Lessons 2–4. `E4` establishes a workable communication mode, not a language/handwriting score. If a component fails, use the specific corrective model, new nonidentical rehearsal example, and recheck before introducing its dependent lesson. A Grade 2 or Grade 3 draft does **not** prove any prerequisite was taught.

Each proposed lesson is **25 minutes as an authoring estimate**. Recheck prerequisite components individually. For the independent reference form allow **untimed** responses and read-aloud, tactile/high-contrast printed table, transcription/speech, diagrams or AAC. Assess the **logic and cited card fields**, not spelling speed, fine-motor control, color perception or accent. Use text labels in every card; color is not an exclusive channel. This adaptation must not supply logical answers.

## Scholarly, source, accessibility and approval gates

- All six cards and rules are *original invented classroom data*; no external source is quoted or licensed. Review exact wording, readability and answer validity before any classroom use.
- A teacher must decide whether the six-card visual/tactile set, screen-reader table, task demands, age fit, number of sessions, response alternatives, thresholds and fresh unseen assessment forms are suitable. No instructional timing or materials inventory has been adopted.
- This pilot is an exercise in **formal inference within stated premises**, not an empirical study or religious verdict. Source review for actual quotations and qualified religious-source/translation/hadith/fiqh review belong to the **separate** Islamic studies tracks; none is bypassed by this neutral pilot.
- Keep real learner entry results, individualized supports, sessions, assignment links and scores outside Git.
