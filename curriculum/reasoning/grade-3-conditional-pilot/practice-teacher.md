# Guided practice P1–P8 — teacher models (draft)

Use with the [learner practice](practice-learner.md) and the [original data](rule-cards.md). For every response require a field, rule, or boundary reason; merely guessing a letter is insufficient for a logic outcome.

| Prompt | Correct answer and reasoning | Feedback / recheck |
| --- | --- | --- |
| **P1** | **A, B**. Those are the only two rows labeled blue among all six rows. | Compare each row’s color label, then request a complete list again. |
| **P2** | **A, B, D**, all with Dot = yes; C, E, F have no dot. | Use one-by-one exhaustive checking rather than a visual guess. |
| **P3** | **False**; **D** has dot yes but is red. R1 (blue → dot) cannot be reversed. | Have learner restate R1 in its original direction. |
| **P4** | **A, C, F** are triangles and **all three** have Stripe = yes. | A single supporting example does not prove an all-claim without checking all rows. |
| **P5** | **False**; **E** has Number = yes but Stripe = no. R3 does not entail its converse. | Point to the exact E cells that settle the claim. |
| **P6** | **triangle → stripe → number** by **R2**, then **R3**. | Name both premises, not only the final arrow; all three triangles A,C,F corroborate the chain. |
| **P7** | **B** or **D** has Dot = yes, Number = no. Dot does not entail number. | Reject the argument even though some dotted cards such as A have numbers. |
| **P8** | **Unknown**. The ledger describes six named cards only. Need the new card’s color entry or an explicit rule for the expanded packet. | Reward a qualified answer rather than guessing from majority frequency. |

### Suggested feedback branches

If the learner reverses an arrow, inspect one disconfirming row, then ask them to restate the condition and consequence. If the learner argues “the rule worked on A” for a universal, require inspection of all rows or **one** counterexample. If a scope mistake appears, draw a boundary around A–F and ask whether the asserted seventh entry exists in the data. Recheck with a *different* statement after coaching; keep actual learner evidence in a private record only.
