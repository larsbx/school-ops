# Fictional workshop rule packet

Original invented data. This is a closed exercise, not a real admission or safety policy. For each card, T = has a token, P = has a partner, H = has a helper pass, C = workshop closed. 1 means yes, 0 means no, ? means not recorded. Each missing field can independently be 0 or 1. The rule is unchanged for every card:

- If closed, do not admit, even if another condition is met.
- If open, admit when the card has both a token and a partner, or has a helper pass (or both).
- Otherwise do not admit.

For an incomplete card, answer "admit" if every compatible completion admits, "do not admit" if none admits, and "undetermined" if some admit and some do not. Do not guess a missing field. The word "or" includes both. The decision concerns only these fictional cards.
