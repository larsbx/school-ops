# Entry and recheck — learner sheet (draft)

All situations invented. Try E first. After feedback, the teacher will provide a different R prompt. Explain by speech, writing, pointing to a row with a dictated reason, or AAC.

**E1.** A card says box sealed: yes; label attached: no; receipt: ?. Which field is known no? Which is missing?

**E2.** A game allows a move only when both a ring and a square are shown. Card A shows both; card B shows just a ring. Which allows the move and why?

**E3.** If a file is marked urgent, it goes in tray 1. A record has no urgency field filled in. Can you conclude it is not urgent? Explain.

**E4.** Three tiles: red round, blue round, red square. A claim says every red tile is round. Find a tile that refutes it and explain why.

## Different rechecks

**R1.** A card says tag present: ?; lid fitted: yes; handle present: no. Name the known no and the missing field.

**R2.** A puzzle opens only when both a star and a moon are shown. Card K has a moon only; L has both. Which opens and why?

**R3.** If a parcel is marked fragile, it receives padding. The fragile field is blank. Can you conclude it is not fragile? Explain.

**R4.** Three tokens: striped square, plain square, striped circle. Refute “every striped token is square.”
