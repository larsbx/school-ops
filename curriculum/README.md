## Add a course

1. Copy the [scope brief](../templates/scope-brief.md) to
   `curriculum/<subject>/<course-slug>/scope.md` and define the course audience.
2. Copy the [course template](../templates/course.md) to the course's `README.md`.
3. Assign a stable course ID and outcome IDs using the
   [curriculum model](../docs/curriculum-model.md).
4. Add a row to this index with a relative link to the course record.
5. Add unit records and lessons beneath the course as they are developed.

Keep placeholder rows in the templates, rather than adding fictitious courses to
this index. Record proposed work in a curriculum proposal issue.
